PART B — Master These 6 Types

Type 1 — Continuous PDF (find k, mean, variance) 5/6 papers

f(x) given on an interval; find k so total area = 1, then find mean and variance.

🟢 In simple words A pdf is a curve. Think of it like a hill of sand — the total amount of sand is always 1 (= total probability). The rule "total area = 1" lets you find k. Mean = the balance point where the hill would balance on a finger.
Total area: ∫f(x)dx = 1 → gives k
Mean (μ) = ∫ x·f(x) dx
E(X²) = ∫ x²·f(x) dx
Variance = E(X²) − (Mean)²
Given: f(x) = k·x(2 − x), 0 ≤ x ≤ 2 We need to find k, then Mean, then Variance.
Find k — use ∫₀² f(x) dx = 1 ∫₀² k·x(2 − x) dx = k · ∫₀² (2x − x²) dx = k · [x² − x³/3]₀² = k · (4 − 8/3) = k · (4/3) Set equal to 1: k · (4/3) = 1 → k = 3/4
Find Mean = ∫₀² x · (3/4)·x(2 − x) dx = (3/4) · ∫₀² (2x² − x³) dx = (3/4) · [2x³/3 − x⁴/4]₀² = (3/4) · (16/3 − 4) = (3/4) · (4/3) = Mean = 1
Find Variance — first compute E(X²) E(X²) = (3/4) · ∫₀² (2x³ − x⁴) dx = (3/4) · [x⁴/2 − x⁵/5]₀² = (3/4) · (8 − 6.4) = (3/4) · 1.6 = 1.2 Variance = E(X²) − (Mean)² = 1.2 − 1 = Variance = 0.2

Type 2 — MGF of Exponential 5/6 papers

Find MGF of f(x) = λe−λx; use it to get mean and SD.

🟢 In simple words MGF stands for Moment Generating Function — it is a "formula machine." Differentiate it once and put t = 0 to get the mean. Differentiate twice and put t = 0 to get E(X²). You rarely need to do the integral yourself — just know the result M(t) = λ/(λ − t) and how to use it.
f(x) = λe−λx, x ≥ 0
M(t) = λ / (λ − t), valid for t < λ
Mean = M′(0) = 1/λ
E(X²) = M″(0) = 2/λ²
Variance = 1/λ² · SD = 1/λ
Given: f(x) = 2e−2x (so λ = 2) Find MGF, then mean and SD.
Derive M(t) M(t) = ∫₀^∞ etx · 2e−2x dx = 2 · ∫₀^∞ e−(2−t)x dx = 2 · [1/(2 − t)] = M(t) = 2/(2 − t), t < 2
Find Mean = M′(0) M′(t) = 2/(2 − t)² M′(0) = 2/4 = Mean = 1/2
Find Variance and SD Variance = 1/λ² = 1/4 SD = 1/λ = 1/2

Type 3 — Poisson Fitting 5/6 papers

Frequency table given; fit a Poisson and find expected (theoretical) frequencies.

🟢 In simple words Poisson counts rare, random events — like how many calls arrive per minute, or how many accidents happen per week. Its only parameter is λ (the average). You find λ from the data, then use the recursive shortcut to build the expected frequency column quickly.
λ = Σ(f · x) / N
Expected freq for x: E(x) = N · e−λ · λˣ / x!
Shortcut (much faster): E(x) = E(x − 1) · λ / x
Data: x = 0,1,2,3,4; f = 122,60,15,2,1; N = 200
Find λ Σfx = 0·122 + 1·60 + 2·15 + 3·2 + 4·1 = 0 + 60 + 30 + 6 + 4 = 100 λ = 100 / 200 = λ = 0.5
Compute E(0) — seed value e−0.5 ≈ 0.6065 E(0) = 200 × 0.6065 = 121
Use shortcut E(x) = E(x−1) · λ / x E(1) = 121 × 0.5 / 1 = 61 E(2) = 61 × 0.5 / 2 = 15 E(3) = 15 × 0.5 / 3 = 3 E(4) ≈ 3 × 0.5 / 4 ≈ 0 (round to 0) Total ≈ 121 + 61 + 15 + 3 + 0 = 200 ✓

Type 4 — Normal Distribution (Z-table) 4/6 papers

Given μ and σ, find a probability or percentage using the Z-table.

🟢 In simple words The normal distribution is the classic bell curve — heights, exam marks, measurement errors all follow it. You convert any value X into a Z-score (how many standard deviations from the mean), then look up Φ(z) in the table. The table gives the area to the LEFT of z.
Z = (X − μ) / σ
P(X < a) = Φ(z)
P(X > a) = 1 − Φ(z)
P(a < X < b) = Φ(z₂) − Φ(z₁)
Φ(−z) = 1 − Φ(z)
Key values: Φ(1) = 0.8413 · Φ(2) = 0.9772 · Φ(1.96) ≈ 0.975
Given: μ = 50, σ = 10. Find P(X > 60). Z = (60 − 50) / 10 = 1 P(X > 60) = 1 − Φ(1) = 1 − 0.8413 = 0.1587 (15.87%)
Find P(40 < X < 60) Z for 40 = (40 − 50)/10 = −1 ; Z for 60 = 1 P = Φ(1) − Φ(−1) = 0.8413 − (1 − 0.8413) = 2(0.8413) − 1 = 0.6826 (68.26%)

Type 5 — Binomial Distribution 4/6 papers

n trials each success/fail; find mean, variance, mode, or expected number of cases from a large group.

🟢 In simple words Binomial = repeat something n times and count successes. Like tossing a coin 4 times and counting heads. p = probability of success each time, q = 1 − p. Mean = how many successes you expect on average.
Mean = np
Variance = npq (q = 1 − p)
Mode = ⌊(n+1)p⌋ (floor = round down)
P(X = k) = C(n,k) · pᵏ · qⁿ⁻ᵏ
Given: 800 families, 4 children each, P(boy) = ½ n = 4, p = q = ½
Mean, Variance, Mode Mean = np = 4 × ½ = 2 Variance = npq = 4 × ½ × ½ = 1 Mode = ⌊(4 + 1) × ½⌋ = ⌊2.5⌋ = 2
P(exactly 2 boys) P(X = 2) = C(4,2) · (½)² · (½)² = 6 · (1/16) = 6/16 = 0.375 Expected families = 800 × 0.375 = 300 families
P(at least 1 boy) P(X ≥ 1) = 1 − P(X = 0) = 1 − (½)⁴ = 1 − 1/16 = 15/16 Expected families = 800 × (15/16) = 750 families

Type 6 — Two Regression Equations 4/6 papers

Data table of X and Y; find the two regression lines (Y on X, and X on Y).

🟢 In simple words Regression finds the best-fit straight line to predict one variable from another. There are two lines: one predicts Y from X (slope b_yx), one predicts X from Y (slope b_xy). Both lines always cross at the point (x̄, ȳ). The square root of the product of the two slopes gives you the correlation coefficient r.
b_yx = (nΣxy − ΣxΣy) / (nΣx² − (Σx)²)
b_xy = (nΣxy − ΣxΣy) / (nΣy² − (Σy)²)
Y on X: Y − ȳ = b_yx (X − x̄)
X on Y: X − x̄ = b_xy (Y − ȳ)
r = √(b_yx · b_xy)
Data: X: 1,2,3,4,5 ; Y: 2,5,3,8,7 n = 5, Σx = 15, Σy = 25, x̄ = 3, ȳ = 5 Σxy = 1·2 + 2·5 + 3·3 + 4·8 + 5·7 = 2 + 10 + 9 + 32 + 35 = 88 Σx² = 1 + 4 + 9 + 16 + 25 = 55 Σy² = 4 + 25 + 9 + 64 + 49 = 151
Find b_yx (slope of Y on X line) b_yx = (5 · 88 − 15 · 25) / (5 · 55 − 15²) = (440 − 375) / (275 − 225) = 65 / 50 = b_yx = 1.3
Find b_xy (slope of X on Y line) b_xy = (5 · 88 − 15 · 25) / (5 · 151 − 25²) = 65 / (755 − 625) = 65 / 130 = b_xy = 0.5
Write the two regression equations Y on X: Y − 5 = 1.3(X − 3) → Y = 1.3X + 1.1 X on Y: X − 3 = 0.5(Y − 5) → X = 0.5Y + 0.5
Find correlation coefficient r r = √(b_yx · b_xy) = √(1.3 × 0.5) = √0.65 = r ≈ 0.806 Positive r → positive correlation between X and Y. ✓

Bonus — Easy Extra Numericals

Rank Correlation (Spearman) 4/6 papers

Two sets of rankings for n items; find how strongly they agree.

ρ = 1 − 6Σd² / [n(n² − 1)]
d = rank in X − rank in Y (for each item)
Data: 5 students. Ranks X: 1,2,3,4,5 ; Ranks Y: 2,1,4,3,5 d values: −1, 1, −1, 1, 0 d² values: 1, 1, 1, 1, 0 → Σd² = 4
Apply formula (n = 5) ρ = 1 − 6 · 4 / [5 · (25 − 1)] = 1 − 24 / 120 = 1 − 0.2 = ρ = 0.8 Strong positive rank agreement.

Karl Pearson Skewness — Definitions

Sk = (Mean − Mode) / SD
Sk = 3(Mean − Median) / SD ← use when mode is ill-defined
Positive Sk → right tail longer (mean > median > mode)
Negative Sk → left tail longer (mean < median < mode)

PART A — Definitions (15 easy marks, learn ALL)

These are the one-liners for Q1 (a)–(j). Write them short, write them first.

TermOne-line answer to write in exam
CDFF(x) = P(X ≤ x); starts at 0, climbs to 1 as x → ∞.
pdfCurve for a continuous random variable; area under it over any interval = probability; total area = 1.
pmfGives exact probabilities for a discrete random variable at each value; all probabilities add to 1.
BinomialCounts successes in n independent yes/no trials; mean = np, variance = npq.
PoissonCounts rare, random events in a fixed interval; mean = variance = λ.
Normal curveSymmetric bell shape; mean = median = mode; total area under curve = 1; fully described by μ and σ.
Exponential (memoryless)Models waiting time; has no memory: P(X > s+t | X > s) = P(X > t); mean = 1/λ.
CovarianceCov(X,Y) = E(XY) − E(X)E(Y); measures joint variation; if X and Y are independent then Cov = 0.
Correlation vs RegressionCorrelation measures strength (r ∈ [−1, 1], symmetric between X and Y). Regression gives a prediction line — asymmetric (Y on X ≠ X on Y).
Skewness typesSymmetric (Sk = 0), Positive (right tail longer; mean > median > mode), Negative (left tail longer).
Kurtosis typesMesokurtic (β₂ = 3, normal bell), Leptokurtic (β₂ > 3, sharp peak), Platykurtic (β₂ < 3, flat top).
Median (small data)Sort all values; odd n → the middle value; even n → average of the two middle values.
Bayes' theoremP(Aᵢ|B) = P(B|Aᵢ)·P(Aᵢ) / Σ P(B|Aⱼ)·P(Aⱼ) — updates probability given new evidence.
