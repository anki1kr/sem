2.1 Supervised learning: regression vs classification

A teacher gives questions WITH answers; the student learns the pattern and then answers new questions. (answer key ke saath padhai)

Definition: Supervised learning is learning a function f that maps an input x to an output y from a training set of labelled pairs (x, y), so that f can predict y for new, unseen x.
  • Features (x) = input attributes; label / target (y) = the known answer.
  • Regression: y is continuous, e.g. predicting a flat's price or tomorrow's temperature.
  • Classification: y is a category, e.g. spam / not spam, pass / fail. (dabba chunna)
  • Training set is used to fit the model; test set checks it on unseen data.
  • Overfitting = model memorises training data and fails on new data; underfitting = model too simple to capture the pattern.
  • Note: KNN and decision trees can also do regression (average of neighbours / leaf mean); SVM has a regression form (SVR).

2.2 Nearest-Neighbours (K-Nearest Neighbours, KNN)

"Tell me who your neighbours are, I'll tell you who you are." A new student in a hostel is guessed to like cricket if most of the nearest roommates do. (jaisa padosi, waisa tum)

Definition: K-Nearest Neighbours is a non-parametric, instance-based supervised algorithm that classifies a new point by the majority class of its k closest training points (for regression: the average of their values), closeness measured by a distance such as Euclidean distance.

Distance formulas (points p = (x1, y1), q = (x2, y2))

  • Euclidean distance (straight-line distance): $$d = \sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2}$$ In $n$ dimensions: $d = \sqrt{\sum (p_i - q_i)^2}$.
  • Manhattan distance $d = |x_1 - x_2| + |y_1 - y_2|$ (city-block distance, like walking along Chandigarh's grid of sectors). (gali-gali chal ke)
  • Minkowski $d = \left(\sum |p_i - q_i|^p\right)^{1/p}$; $p = 1$ gives Manhattan, $p = 2$ gives Euclidean.

Key points

  • Choosing k: small $k$ ($k = 1$) is noisy and overfits; large $k$ smooths too much and underfits. Pick $k$ by trying values on validation data; a common rule of thumb starts near $\sqrt{n}$.
  • Odd k for two classes avoids a tie in voting ($k = 3, 5, 7$).
  • Feature scaling is compulsory: a feature measured in lakhs (salary) swamps one measured in years (age). Use min-max normalisation or standardisation first.
  • Lazy learner: no training phase, it just stores data; all work happens at prediction time, so prediction is slow for big data. (exam ke din hi padhta hai)
  • Weighted KNN: closer neighbours get larger vote weight (e.g. $1/\text{distance}$).

Feature scaling before KNN

KNN is purely distance-based, so a feature on a bigger numeric scale (salary in ₹) silently dominates one on a small scale (age in years). Min-Max normalisation fixes this: $$x' = \frac{x - x_{min}}{x_{max} - x_{min}}$$

Worked example (computed in Python, 4 decimals) · A(20, 30000) No, B(25, 40000) No, C(30, 50000) Yes, D(35, 60000) Yes; query $Q = (28, 45000)$, $k=1$
Age: min 20, max 35 → $Q'_{age} = \dfrac{28-20}{35-20} = 0.533$. Salary: min 30000, max 60000 → $Q'_{sal} = \dfrac{45000-30000}{60000-30000} = 0.500$
Scaled table: A(0, 0), B(0.333, 0.333), C(0.667, 0.667), D(1, 1). Distances from $Q' = (0.533, 0.500)$: A 0.7311, B 0.2603, C 0.2134, D 0.6839
Nearest = C → Q is classified Yes (without scaling, the salary column alone would have decided the answer)

Weighted KNN

Weighted KNN gives each neighbour a vote of $$w_i = \frac{1}{d_i}$$ instead of one vote each, so one very close neighbour can outweigh two farther ones.

Worked example (computed in Python, 3 decimals) · nearest 3 of some query: A dist 0.5 Red, B dist 1.5 Blue, C dist 2 Blue
Ordinary majority vote: Blue = 2, Red = 1 → Blue
Weights $w = 1/d$: $w_A = 1/0.5 = 2$, $w_B = 1/1.5 = 0.667$, $w_C = 1/2 = 0.5$
Weighted vote: Red $= 2$; Blue $= 0.667 + 0.5 = 1.167$
Weighted KNN → Red — the OPPOSITE of the majority vote, because A is so close it outweighs B and C together

KNN for regression

For a numeric target, KNN averages the neighbours' values instead of voting: plain average $\hat{y} = \dfrac{1}{k}\sum y_i$, or weighted $\hat{y} = \dfrac{\sum w_i y_i}{\sum w_i}$ with $w_i = 1/d_i$.

Worked example (computed in Python, 2 decimals) · house size vs price (₹ lakh): A(1000,50) B(1200,60) C(1500,75) D(1800,90) E(2000,100); predict the price at size 1600, $k=3$
Distances (1D, $|x_1-x_2|$): C 100, D 200, B 400 are the 3 nearest → prices 75, 90, 60
Plain average: $\hat{y} = \dfrac{75+90+60}{3} = 75$
Weighted ($w = 1/d$): $w_C = 0.01$, $w_D = 0.005$, $w_B = 0.0025$; $\hat{y} = \dfrac{0.01(75)+0.005(90)+0.0025(60)}{0.01+0.005+0.0025} = \dfrac{1.35}{0.0175}$
Plain average $= 75$; weighted average $\approx 77.14$

Categorical features and tie-breaking

  • When features are categories, not numbers, use a matching (Hamming) distance: $d = $ number of mismatched attributes.
  • Tie (equal votes, e.g. $k=4$ giving 2-2): break it by (a) the single closest neighbour's class, (b) switching to an odd $k$, (c) weighted KNN, or (d) a fixed rule decided in advance.
Worked example · A(Young,High) No, B(Young,Medium) No, C(Middle,High) Yes, D(Old,High) Yes; query (Middle, High)
Mismatches: A = 1 (Age differs), B = 2 (both differ), C = 0 (both match), D = 1 (Age differs)
Nearest = C (distance 0) → Purchased = Yes

Choosing k, and judging the classifier

Try several $k$ on validation data and keep the one with the highest accuracy $\left(\text{Accuracy} = \dfrac{\text{Correct}}{\text{Total}} \times 100\right)$.

2.3 Decision Trees (ID3, entropy, information gain, Gini)

A decision tree is a game of "20 questions": ask the most useful question first, then keep asking until the answer is clear. (sawaal pe sawaal, jawab tak)

Definition: A decision tree is a tree-shaped supervised model in which each internal node tests an attribute, each branch is an outcome of the test, and each leaf node holds a class label (or a value, for regression). Prediction follows one path from root to leaf.

Formulas

  • Entropy (impurity, disorder): $$H(S) = -\sum p_i \log_2 p_i$$ where $p_i$ = fraction of class $i$. $H = 0$ for a pure set; $H = 1$ for a 50-50 two-class set. (kitna ghalmel hai)
  • Information gain: $$IG(S,A) = H(S) - \sum_v \frac{|S_v|}{|S|} H(S_v)$$ ID3 picks the attribute with maximum gain.
  • Gini index (used by CART): $$Gini(S) = 1 - \sum p_i^2$$ 0 = pure, 0.5 = worst for two classes. CART picks the split with the lowest weighted Gini and builds binary trees.
  • ID3 (Quinlan) uses information gain; C4.5 improves it with gain ratio and handles numeric attributes; CART uses Gini.

Overfitting and pruning

  • Overfitting: a fully grown tree keeps splitting until every leaf is pure, learning noise; it scores well on training data but poorly on test data.
  • Pre-pruning (early stopping): stop growing when depth limit, minimum samples per node, or minimum gain is reached.
  • Post-pruning: grow the full tree, then remove sub-trees that do not improve accuracy on validation data (e.g. reduced-error pruning, cost-complexity pruning in CART). (faltu shaakhein kaat do)

Entropy for more than two classes

The same $-\sum p_i \log_2 p_i$ formula works for any number of classes, not only Yes/No.

Worked example (computed in Python, 4 decimals) · a node has Class A = 3, Class B = 2, Class C = 1
$P(A)=0.5$, $P(B)=0.3333$, $P(C)=0.1667$
$H(S) = -0.5\log_2 0.5 - 0.3333\log_2 0.3333 - 0.1667\log_2 0.1667 = 0.5000+0.5283+0.4308$
$H(S) \approx 1.4591$ (more classes can push entropy above 1 — the maximum for 3 equally-likely classes is $\log_2 3 \approx 1.585$)

Gain ratio and split information (used by C4.5)

  • Information gain alone favours an attribute that splits into many small groups (like an ID number: gain $\approx 1$ but useless for prediction). C4.5 corrects this with the gain ratio: $$GainRatio(S,A) = \frac{IG(S,A)}{SplitInfo(A)}, \qquad SplitInfo(A) = -\sum_v \frac{|S_v|}{|S|}\log_2 \frac{|S_v|}{|S|}$$
  • $SplitInfo$ has the same "$-\sum p \log_2 p$" shape as entropy, but over the SIZES of the groups, not the class labels. C4.5 picks the attribute with the highest gain ratio.
Worked example (computed in Python, 4 decimals) · parent entropy $0.80$; Attribute A splits 5/5, weighted entropy 0.40; Attribute B splits 8/2, weighted entropy 0.50
$IG(A) = 0.80-0.40 = 0.40$; $SplitInfo(A) = -0.5\log_2 0.5 - 0.5\log_2 0.5 = 1.0000$ → $GainRatio(A) = 0.4000$
$IG(B) = 0.80-0.50 = 0.30$; $SplitInfo(B) = -0.8\log_2 0.8 - 0.2\log_2 0.2 = 0.7219$ → $GainRatio(B) = 0.4156$
$GainRatio(B) \gt GainRatio(A)$ → C4.5 selects B, even though A had the higher raw information gain
Common mistake: C4.5 does NOT pick the attribute with the highest information gain — it picks the highest GAIN RATIO, precisely to remove IG's bias toward attributes with many distinct values.

Gini reduction

  • Gini reduction $= Gini(\text{parent}) - \text{weighted } Gini$; CART picks the split with the highest reduction (the same choice as minimum weighted Gini).
Worked example (computed in Python, 4 decimals) · parent 6 Yes, 4 No; a split gives weighted Gini $= 0.16$
$Gini(\text{parent}) = 1-(0.6)^2-(0.4)^2 = 0.4800$
Gini reduction $= 0.48-0.16 = 0.32$

Splitting a continuous attribute

C4.5/CART handle a numeric attribute (like Temperature) by testing a threshold and treating it as a two-way split, "$\le$ threshold" vs "$\gt$ threshold" — the threshold is chosen the same way as any other split, by maximum gain.

2.4 Naive Bayes classifier

A doctor guesses the disease by combining "how common is it" with "how typical are these symptoms for it". (pehle ka andaaza + naya saboot)

Definition: Naive Bayes is a probabilistic classifier based on Bayes' theorem that assumes all features are conditionally independent given the class; it predicts the class with the highest posterior probability $P(C \mid X)$.
  • Bayes' theorem: $$P(C \mid X) = \frac{P(X \mid C)\,P(C)}{P(X)}$$
  • Prior $P(C)$: belief about the class before seeing features.
  • Likelihood $P(X \mid C)$: how probable the features are if the class is C.
  • Posterior $P(C \mid X)$: updated probability after seeing features. Evidence $P(X)$ is the same for every class, so it can be ignored when comparing.
  • Conditional independence ("naive" assumption): $$P(x_1, x_2, \dots, x_n \mid C) = P(x_1 \mid C) \cdot P(x_2 \mid C) \cdots P(x_n \mid C)$$ Rarely true in real life, yet the classifier works well. (sab features apne-apne, bhole-bhaale)
  • Laplace smoothing: if any count is 0, the whole product becomes 0. Use $P(x_i \mid C) = \dfrac{\text{count} + 1}{n_C + k}$, where $k$ = number of values of that feature.

The classification rule (argmax)

Putting prior and likelihood together, Naive Bayes always picks the class with the highest score: $$\hat{C} = \arg\max_C \; P(C)\prod_i P(x_i \mid C)$$

A pure Bayes' theorem numerical (medical test)

Not every Bayes question needs the "naive" independence step — this classic one is plain Bayes' theorem.

Worked example (computed in Python, 2 decimals) · $P(\text{Disease}) = 0.10$, $P(\text{Positive} \mid \text{Disease}) = 0.90$, $P(\text{Positive}) = 0.18$. Find $P(\text{Disease} \mid \text{Positive})$
$$P(\text{Disease} \mid \text{Positive}) = \frac{P(\text{Positive} \mid \text{Disease})\,P(\text{Disease})}{P(\text{Positive})} = \frac{0.90 \times 0.10}{0.18} = \frac{0.09}{0.18}$$
$P(\text{Disease} \mid \text{Positive}) = 0.50$ (50%)
Common mistake: $P(\text{Positive} \mid \text{Disease})$ and $P(\text{Disease} \mid \text{Positive})$ are NOT the same number — swapping likelihood and posterior is one of the most common Bayes' theorem errors.

Gaussian Naive Bayes (continuous features)

Counting rows does not work for a continuous feature like age or marks, because an exact value may never repeat in the training data. Gaussian NB instead assumes the feature is normally distributed within each class: $$P(x \mid C) = \frac{1}{\sqrt{2\pi\sigma_C^2}}\, e^{-\frac{(x-\mu_C)^2}{2\sigma_C^2}}$$

Worked example (computed in Python, 5 decimals) · Class A: $P(A)=0.6$, $\mu=50$, $\sigma=10$; Class B: $P(B)=0.4$, $\mu=70$, $\sigma=10$; classify $x=55$
$P(55 \mid A) = \dfrac{1}{10\sqrt{2\pi}} e^{-\frac{(55-50)^2}{2(10)^2}} \approx 0.03520$
$P(55 \mid B) = \dfrac{1}{10\sqrt{2\pi}} e^{-\frac{(55-70)^2}{2(10)^2}} \approx 0.01295$
$Score(A) = 0.6 \times 0.03520 = 0.02112$; $Score(B) = 0.4 \times 0.01295 = 0.00518$
Posterior: $P(A\mid x) = \dfrac{0.02112}{0.02112+0.00518} \approx 0.80$
$Score(A) \gt Score(B)$ → Prediction = A (about 80% posterior)

Why implementations use log probabilities

Multiplying many probabilities (0.5 × 0.1 × 0.01 × …) quickly gives a number so small a computer rounds it to 0 (underflow). Taking logs turns the product into a sum, which never underflows: $$\log Score(C) = \log P(C) + \sum_i \log P(x_i \mid C)$$

Worked example (computed in Python, 4 decimals) · $P(C)=0.2$, $P(X_1\mid C)=0.5$, $P(X_2\mid C)=0.1$
Direct: $Score = 0.2 \times 0.5 \times 0.1 = 0.0100$
Log form (natural log): $\ln 0.2 + \ln 0.5 + \ln 0.1 = -1.6094-0.6931-2.3026 = -4.6052$
$e^{-4.6052} = 0.0100$ — the same score, computed by addition instead of multiplication

2.5 Linear models: Linear Regression

Fit the straightest ruler line through scattered dots so that the dots are, on average, as close to the line as possible. (beech se seedhi line)

Definition: Linear regression is a supervised regression method that models a continuous output as a linear function of the input, $\hat{y} = \beta_0 + \beta_1 x$, with $\beta_0$ (intercept) and $\beta_1$ (slope) found by the least squares method, i.e. minimising the sum of squared errors. (Class notes write this as $y = mx + c$, where $m = \beta_1$ is the slope and $c = \beta_0$ is the intercept.)
  • Model: $$y = \beta_0 + \beta_1 x + \varepsilon$$ $\beta_0$ = intercept (value when $x = 0$), $\beta_1$ = slope (change in $y$ per unit $x$), $\varepsilon$ = error.
  • Residual $e_i = y_i - \hat{y}_i$. Least squares chooses $\beta_0, \beta_1$ to minimise $$SSE = \sum e_i^2 = \sum (y_i - \hat{y}_i)^2$$
  • MSE $= SSE/n$. $R^2$: $$R^2 = 1 - \frac{SS_{res}}{SS_{tot}} = 1 - \frac{SSE}{SST}$$ where $SST = \sum (y_i - \bar{y})^2$; $R^2$ = fraction of variance explained (1 = perfect fit).
  • MAE (Mean Absolute Error) $$MAE = \frac{1}{n}\sum |y_i - \hat{y}_i|$$ averages the absolute error — no squaring, so a few huge errors don't dominate as much as in MSE. RMSE $= \sqrt{MSE}$, back in the same unit as $y$ (MSE's own unit is $y$ squared).
  • Gradient descent (iterative alternative): (1) start with $\beta_0 = \beta_1 = 0$; (2) compute gradient of MSE w.r.t. each coefficient; (3) update $\beta_j := \beta_j - \alpha \cdot \text{gradient}$ ($\alpha$ = learning rate) and repeat until the error stops falling.
  • Multiple linear regression: $y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \dots + \beta_n x_n$ (many inputs, e.g. price from area, rooms, floor).
  • Assumptions: linear relation, independent errors, constant error variance, no strong multicollinearity.

2.6 Multiple Linear Regression

Real prices rarely depend on just one thing — a flat's price depends on area AND rooms AND floor together; give the line one slope per input instead of one. (ek nahi, kai factors ek saath)

Definition: Multiple Linear Regression is Linear Regression with two or more independent variables: $$\hat{y} = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \dots + \beta_n x_n$$ found the same way, by least squares, over ALL the inputs at once. (Class notes write the coefficients as $b_0, b_1, \dots, b_n$ — same meaning as $\beta_0, \beta_1, \dots, \beta_n$.)
  • General equation (two or more inputs): at least TWO independent variables are needed — one input variable is Simple Linear Regression (§2.5), not Multiple.
  • Interpreting a coefficient: $\beta_j$ = expected change in $\hat{y}$ for a one-unit increase in $x_j$, holding every other input constant. e.g. if $\hat{y}=20+5x_1+2x_2$ and $x_1$ increases by 3 (with $x_2$ fixed), $\hat{y}$ increases by $5 \times 3 = 15$.
  • Coefficient estimation uses the same least-squares idea as simple regression, generalised to a matrix normal equation: $$\beta = (X^TX)^{-1}X^TY$$ where $X$ is the design matrix (a column of 1's for the intercept, plus one column per input) and $Y$ is the actual output column.
  • Multicollinearity: two or more inputs that are themselves highly correlated make the coefficient estimates unstable and hard to interpret. Diagnosed with the Variance Inflation Factor $$VIF_j = \frac{1}{1-R_j^2}$$ (bigger VIF = more collinearity); e.g. $R_j^2=0.80 \Rightarrow VIF_j = 1/(1-0.80) = 5$.
  • Assumptions: linearity, independent observations, homoscedasticity (residual variance roughly constant), residuals roughly normal, and low multicollinearity.
  • Error metrics — MSE, MAE, RMSE, $R^2$ — are computed exactly as in §2.5, just summed over every row using this multi-input $\hat{y}$.

2.7 Linear models: Logistic Regression

Take the linear score, squash it into a probability between 0 and 1, then say "Yes" if it is above 0.5. (score ko 0-1 mein dabao)

Definition: Logistic regression is a supervised classification method that models the probability of the positive class as $$p = \sigma(z) = \frac{1}{1 + e^{-z}}$$ where $z = \beta_0 + \beta_1 x_1 + \dots + \beta_n x_n$, and assigns class 1 when $p \ge 0.5$. (Class notes write $z = wx+b$, where $w=\beta_1$ is the weight and $b=\beta_0$ is the bias.)
  • Sigmoid $\sigma(z) = \dfrac{1}{1 + e^{-z}}$: $\sigma(0) = 0.5$, $\sigma(+\infty) \to 1$, $\sigma(-\infty) \to 0$.
  • Odds compare success to failure: $$Odds = \frac{p}{1-p}$$ e.g. $p=0.8 \Rightarrow Odds = 0.8/0.2 = 4$, meaning success is 4 times as likely as failure.
  • Log-odds (logit): $\ln \dfrac{p}{1 - p} = z = \beta_0 + \beta_1 x$. The model is linear in the log-odds, hence a "linear model".
  • Decision boundary: $p = 0.5$ exactly where $z = 0$, i.e. $\beta_0 + \beta_1 x_1 + \dots = 0$ → a straight line / hyperplane. e.g. $p=\sigma(-6+2x)$: boundary where $-6+2x=0 \Rightarrow x=3$; so $x \gt 3 \to$ class 1, $x \lt 3 \to$ class 0.
  • The threshold need not be 0.5 — e.g. disease screening may use $0.3$ so fewer true cases are missed (accepting more false alarms), trading precision for recall.
  • Log-loss (binary cross-entropy), with $\hat{y}_i = p$ for example $i$: $$L = -\frac{1}{n}\sum \left[y_i \log \hat{y}_i + (1-y_i)\log(1-\hat{y}_i)\right]$$ weights are learned by minimising it with gradient descent (no closed form).
  • Multi-class: one-vs-rest or softmax (multinomial) logistic regression.

  • Maximum Likelihood Estimation: choose the weights ($\beta_0,\beta_1,\dots$) that make the OBSERVED training labels most probable under the model — i.e. maximise the likelihood of the data actually seen.
  • For logistic regression, maximising the likelihood is the SAME optimisation problem as minimising the log-loss cost function above (log-loss is the negative log-likelihood) — this is why gradient descent on log-loss finds the MLE weights.
  • Analogy: among several doctors with different diagnostic accuracy, you would trust the one whose past diagnoses were most often correct; MLE "trusts" the parameter values that best explain the data actually observed.

2.8 Linear models: Support Vector Machines (SVM)

Separate two groups with the widest possible road, not just any line; the points touching the road's edges decide where it goes. (sabse chaudi sadak beech mein)

Definition: A Support Vector Machine is a supervised classifier that finds the hyperplane $w^T x + b = 0$ separating two classes with the maximum margin; the training points lying on the margin boundaries are called support vectors.
  • Hyperplane: $$w^T x + b = 0$$ (a line in 2D, plane in 3D). $w$ = normal (perpendicular) vector, $b$ = bias.
  • Margin: distance between the planes $w^T x + b = +1$ and $w^T x + b = -1$, equal to $$\text{margin} = \frac{2}{\lVert w \rVert}$$ Maximising margin = minimising $\frac{1}{2}\lVert w \rVert^2$.
  • Support vectors: points with $y_i(w^T x_i + b) = 1$, lying on the margin boundary; only they decide the hyperplane. Removing other points does not change it.
  • Hard margin: no point allowed inside the margin; works only for perfectly separable data.
  • Soft margin: slack variables $\xi_i$ allow some violations; minimise $\frac{1}{2}\lVert w \rVert^2 + C \sum \xi_i$. C large = few violations, narrow margin (risk overfit); C small = wide margin, more violations. (C = galti ki saza)
  • Prediction: class $= \text{sign}(w^T x + b)$. Multi-class via one-vs-one or one-vs-rest.

Why a linear boundary fails

  • XOR problem: points (0,0), (1,1) in class 0 and (0,1), (1,0) in class 1 cannot be split by any single straight line.
  • Circular data: one class inside a circle, the other in a ring around it; boundary must be a circle, not a line.

2.10 Hypothesis function and Cost function (with derivation)

The hypothesis is the model's guess; the cost function is one number that says how wrong all the guesses are together. Training = pushing that number down. (guess kitna galat hai, uska ek score)

Definition (Hypothesis function): The hypothesis function $h(x)$ is the function a learning algorithm uses to map an input $x$ to a predicted output. For linear regression: $$h(x) = \beta_0 + \beta_1 x$$ For logistic regression: $$h(x) = \sigma(\beta_0 + \beta_1 x) = \frac{1}{1 + e^{-(\beta_0 + \beta_1 x)}}$$ The set of all possible $h$ is the hypothesis space.
Definition (Cost function): A cost function $J(\beta_0, \beta_1)$ measures the average error of the hypothesis over all $m$ training examples. Learning means finding the parameters $\beta_0, \beta_1$ that minimise $J(\beta_0, \beta_1)$.

Cost function for linear regression (Mean Squared Error form)

  • Error of one example: $h(x_i) - y_i = \hat{y}_i - y_i$ (predicted minus actual).
  • Cost: $$J(\beta_0,\beta_1) = \frac{1}{2m}\sum_{i=1}^{m} \big(h(x_i) - y_i\big)^2$$
  • Why square? Positive and negative errors cannot cancel, big errors are punished more, and the result is a smooth bowl that is easy to differentiate. (minus-plus cancel na ho)
  • Why $1/2$? Only for convenience: the 2 from differentiating the square cancels it. The minimum is at the same $\beta_0, \beta_1$ either way.
  • $J(\beta_0, \beta_1)$ for linear regression is convex (one bowl, one minimum), so gradient descent cannot get stuck in a wrong valley.

Derivation: minimising J (least-squares formulas)

Derivation
Step 1. $$J(\beta_0,\beta_1) = \frac{1}{2m}\sum (\beta_0 + \beta_1 x_i - y_i)^2$$
Step 2. Partial derivative w.r.t. $\beta_0$ (chain rule, the 2 cancels the $1/2$):
$$\frac{\partial J}{\partial \beta_0} = \frac{1}{m}\sum (\beta_0 + \beta_1 x_i - y_i)$$
Step 3. Partial derivative w.r.t. $\beta_1$ (inner derivative is $x_i$):
$$\frac{\partial J}{\partial \beta_1} = \frac{1}{m}\sum (\beta_0 + \beta_1 x_i - y_i) \cdot x_i$$
Step 4. At the minimum both are 0. From $\dfrac{\partial J}{\partial \beta_0} = 0$: $\sum y_i = m\beta_0 + \beta_1 \sum x_i$ ⇒ $$\beta_0 = \bar{y} - \beta_1 \bar{x}$$
Step 5. From $\dfrac{\partial J}{\partial \beta_1} = 0$: $\sum x_i y_i = \beta_0 \sum x_i + \beta_1 \sum x_i^2$
Step 6. Substitute $\beta_0 = \bar{y} - \beta_1 \bar{x}$ and simplify:
$$\beta_1 = \frac{\sum (x_i-\bar{x})(y_i-\bar{y})}{\sum (x_i-\bar{x})^2}$$
$$\beta_1 = \frac{\sum (x_i-\bar{x})(y_i-\bar{y})}{\sum (x_i-\bar{x})^2}, \qquad \beta_0 = \bar{y} - \beta_1 \bar{x}$$

These are exactly the formulas used for $\beta_1$ and $\beta_0$ in section 2.5, so the least-squares line is the line with the lowest possible cost.

Gradient descent (when there is no closed form, or too many features)

  • Update rule (repeat until convergence, update both together): $$\beta_0 := \beta_0 - \alpha \cdot \frac{1}{m}\sum (h(x_i) - y_i)$$ $$\beta_1 := \beta_1 - \alpha \cdot \frac{1}{m}\sum (h(x_i) - y_i) \cdot x_i$$
  • $\alpha$ (learning rate): too small = very slow; too large = jumps over the minimum and can diverge.
  • Convergence: stop when the cost barely decreases any further, the gradient is close to 0, or a fixed number of iterations is reached — practically "close enough" to the minimum, not necessarily the exact minimum.

Cost function for logistic regression (log loss)

  • $$J(\beta_0,\beta_1) = -\frac{1}{m}\sum \left[y_i \log h(x_i) + (1-y_i)\log\big(1-h(x_i)\big)\right]$$
  • Why not MSE? Squaring the error of a sigmoid gives a non-convex cost with many local minima; log loss is convex.
  • Intuition: $y = 1$ and $h$ near 1 ⇒ cost near 0; $y = 1$ and $h$ near 0 ⇒ $-\log h$ is huge. Confident wrong answers are punished hardest. (pakka galat = sabse bada penalty)
  • Its gradient has the same shape as linear regression: $\dfrac{\partial J}{\partial \beta_j} = \dfrac{1}{m}\sum (h(x_i) - y_i)\, x_{ij}$; only $h$ is different.
  • Minimising $J$ here is the same problem as Maximum Likelihood Estimation: log loss is the negative log-likelihood, so the $\beta$ that minimises $J$ is exactly the $\beta$ that makes the observed training labels most probable.
  • e.g. one example, actual $y=1$, predicted $p=0.8$: $L=-\log(0.8)\approx0.223$ (natural log; small because the model was confident AND correct).

2.11 Outliers

An outlier is the one value that does not look like the rest, like a ₹5 crore salary in a list of ₹30,000 salaries. (bheed se bilkul alag value)

Definition: An outlier is a data point that differs significantly from the other observations in a dataset. It may be caused by measurement or entry error, or it may be a genuine but rare event.
  • Global / point outlier: far from every other value, e.g. age = 250 in a student table.
  • Contextual outlier: normal in one context, abnormal in another, e.g. 35 °C is normal in May in Delhi but abnormal in January.
  • Collective outlier: individual points look fine but together they are unusual, e.g. many small transfers from one account in one minute (possible fraud).
  • Causes: typing / measurement errors, sensor faults, data merged from different units (cm vs m), or genuine rare events (fraud, disease).
  • Effects: pull the mean, inflate variance, tilt a regression line, and distort distance-based methods like KNN and K-means.

Detecting outliers

  • IQR method: $IQR = Q_3 - Q_1$. Outlier if $$\text{value} \lt Q_1 - 1.5 \cdot IQR \quad \text{or} \quad \text{value} \gt Q_3 + 1.5 \cdot IQR$$ Robust, because quartiles are not moved by the outlier.
  • Z-score method: $z = \dfrac{x - \mu}{\sigma}$; outlier if $|z| \gt 3$ (sometimes 2 or 2.5). Assumes roughly normal data.
  • Visual: box plot, scatter plot, histogram.
  • Model based: distance to nearest neighbours (KNN distance), clustering (points far from every cluster), isolation forest.

2.12 Ensemble Learning (Bagging, Boosting, Stacking)

Ask several models instead of one and combine their answers, like a panel of judges instead of one judge. (ek ki jagah kai logon ki raay)

Definition: Ensemble learning combines the predictions of multiple base models (weak learners) to produce a single prediction that is more accurate and stable than any individual model.
  • Why it works: different models make different mistakes; when their errors are not all the same, combining them cancels many errors.
  • Weak learner: a model only slightly better than random guessing (e.g. a depth-1 decision tree called a stump).
  • Bagging mainly reduces variance (overfitting); boosting mainly reduces bias (underfitting).
  • Condition: base models must be better than random (accuracy $\gt 50\%$ for 2 classes) and reasonably diverse.
Worked example: why voting helps (computed in Python) · 3 independent classifiers, each 70% accurate, majority vote
Vote is correct when at least 2 of 3 are correct
$P(\text{all 3 correct}) = 0.7^3 = 0.343$
$P(\text{exactly 2 correct}) = 3 \times 0.7^2 \times 0.3 = 0.441$
$P(\text{ensemble correct}) = 0.343 + 0.441 = 0.784$
With 5 such classifiers (at least 3 correct): 0.837

1. Bagging (Bootstrap Aggregating)

  • Bootstrap sample: pick m rows with replacement from m rows; some rows repeat, some are left out.
  • On average a bootstrap sample contains about 63.2% of the distinct rows ($1 - 1/e$); the left-out rows are the out-of-bag data, usable for testing.
  • Models are trained independently and in parallel, all with equal weight.
  • Random Forest = bagging of decision trees + at each split only a random subset of features is considered, which makes the trees more different from each other.

2. Boosting

  • Models are trained sequentially; every new model gives more importance to the examples the previous models got wrong.
  • AdaBoost: increases the weight of misclassified examples; each model gets a vote weight based on its accuracy.
  • Gradient Boosting (and XGBoost): each new tree is fitted to the remaining errors (residuals) of the ensemble so far.
  • Risk: can overfit noisy data and outliers, because it keeps chasing hard (possibly wrong) points.

3. Stacking and 4. Voting

  • Stacking: different kinds of base models (e.g. KNN, SVM, decision tree) make predictions; a second-level meta-learner (often logistic regression) learns how to combine them.
  • Hard voting: majority class label wins. Soft voting: average the predicted probabilities, pick the highest.

2.14 Short answers (1 mark)

Q1. Differentiate regression and classification.
Regression predicts a continuous value (e.g. price); classification predicts a discrete class label (e.g. spam / not spam). Linear regression vs logistic regression is the standard pair.
Q2. Why is KNN called a lazy learner?
It builds no model during training; it only stores the data and does all computation (distances, voting) at prediction time.
Q3. Write the Euclidean and Manhattan distance formulas.
Euclidean $d = \sqrt{\sum (p_i - q_i)^2}$; Manhattan $d = \sum |p_i - q_i|$.
Q4. Why is an odd value of k preferred in KNN?
For two-class problems an odd k prevents a tie in the majority vote.
Q5. Define entropy.
Entropy measures impurity of a set: $H(S) = -\sum p_i \log_2 p_i$. It is 0 for a pure set and 1 for an equal two-class split.
Q6. What is information gain?
Reduction in entropy after splitting on attribute $A$: $IG(S,A) = H(S) - \sum_v \frac{|S_v|}{|S|} H(S_v)$. ID3 splits on the attribute with the highest gain.
Q7. Define Gini index.
$Gini = 1 - \sum p_i^2$; an impurity measure used by CART; 0 means pure, lower weighted Gini means a better split.
Q8. What is pruning?
Removing branches of a decision tree that add little accuracy, to reduce overfitting. Pre-pruning stops growth early; post-pruning cuts a fully grown tree.
Q9. State Bayes' theorem.
$P(C \mid X) = \dfrac{P(X \mid C)\,P(C)}{P(X)}$: posterior = likelihood × prior / evidence.
Q10. Why is Naive Bayes called "naive"?
It assumes all features are conditionally independent of each other given the class, which is rarely true in practice.
Q11. What is Laplace smoothing?
Adding 1 to every count, $P = \dfrac{\text{count} + 1}{n + k}$, so that an unseen feature value does not make the whole probability zero.
Q12. What is the least squares method?
Choosing regression coefficients that minimise the sum of squared residuals $\sum (y_i - \hat{y}_i)^2$; gives $\beta_1 = \dfrac{\sum (x_i-\bar{x})(y_i-\bar{y})}{\sum (x_i-\bar{x})^2}$, $\beta_0 = \bar{y} - \beta_1 \bar{x}$.
Q13. What does $R^2$ indicate?
$R^2 = 1 - \dfrac{SS_{res}}{SS_{tot}}$, the proportion of variance in y explained by the model; closer to 1 means better fit.
Q14. Write the sigmoid function and its role.
$\sigma(z) = \dfrac{1}{1 + e^{-z}}$; it converts the linear score of logistic regression into a probability between 0 and 1.
Q15. What are support vectors?
Training points lying on the margin boundaries $w^T x + b = \pm 1$; they alone determine the SVM hyperplane.
Q16. Define margin in SVM.
The distance between the two margin boundaries on either side of the hyperplane, equal to $2/\lVert w \rVert$; SVM maximises it.
Q17. What is the kernel trick?
Replacing dot products $x_i \cdot x_j$ with a kernel $K(x_i, x_j) = \varphi(x_i) \cdot \varphi(x_j)$, so a linear algorithm works in a higher-dimensional space without computing $\varphi$ explicitly.
Q18. Name any four kernel functions.
Linear $x \cdot z$; polynomial $(x \cdot z + c)^d$; RBF/Gaussian $e^{-\gamma \lVert x-z \rVert^2}$; sigmoid $\tanh(\kappa\, x \cdot z + c)$.
Q19. What is a hypothesis function?
The function $h(x)$ a model uses to map input to predicted output; for linear regression $h(x) = \beta_0 + \beta_1 x$.
Q20. Define cost function. Write it for linear regression.
A function $J(\beta_0, \beta_1)$ measuring the average prediction error over all training examples; $J(\beta_0, \beta_1) = \dfrac{1}{2m}\sum (h(x_i) - y_i)^2$. Training minimises it.
Q21. Why is MSE not used as the cost for logistic regression?
With a sigmoid hypothesis the squared-error cost is non-convex (many local minima); log loss is convex, so gradient descent reaches the global minimum.
Q22. What is an outlier? Name its types.
A data point far from the other observations. Types: global (point), contextual, collective.
Q23. State the IQR rule for outliers.
$IQR = Q_3 - Q_1$; a value below $Q_1 - 1.5 \cdot IQR$ or above $Q_3 + 1.5 \cdot IQR$ is an outlier.
Q24. What is ensemble learning?
Combining predictions of several base models (by voting, averaging or a meta-learner) to get better accuracy and stability than any single model.
Q25. Differentiate bagging and boosting.
Bagging trains models in parallel on bootstrap samples with equal votes and reduces variance (Random Forest). Boosting trains sequentially, re-weighting misclassified points, and reduces bias (AdaBoost).
Q26. What is weighted KNN?
Each neighbour votes with weight $w_i = 1/d_i$ instead of one vote each, so a very close neighbour can outweigh several farther ones; used for classification (weighted vote) and regression (weighted average).
Q27. Why must KNN features usually be scaled?
KNN is purely distance-based, so a feature on a larger numeric scale (e.g. salary) would dominate the distance over a small-scale feature (e.g. age); Min-Max normalisation $x' = \dfrac{x-x_{min}}{x_{max}-x_{min}}$ fixes this.
Q28. Write the Minkowski distance and its special cases.
$d = \left(\sum |p_i-q_i|^p\right)^{1/p}$; $p=1$ gives Manhattan distance, $p=2$ gives Euclidean distance.
Q29. What is Gain Ratio, and why does C4.5 use it instead of plain Information Gain?
$GainRatio(S,A) = IG(S,A)/SplitInfo(A)$. Plain IG is biased toward an attribute with many distinct values (like an ID number); dividing by SplitInfo removes that bias.
Q30. What is Gini reduction?
$Gini(\text{parent}) - \text{weighted } Gini$ of the split; CART picks the split with the highest reduction, equivalent to the lowest weighted Gini.
Q31. How does a decision tree split a continuous attribute?
It tests a threshold value and treats it as a two-way split ("$\le$ threshold" vs "$\gt$ threshold"); the threshold is chosen like any other split, by whichever value gives the maximum gain.
Q32. What is Gaussian Naive Bayes?
The Naive Bayes variant used for continuous features: each feature is assumed normally distributed within a class, $P(x\mid C) = \dfrac{1}{\sqrt{2\pi\sigma_C^2}} e^{-(x-\mu_C)^2/2\sigma_C^2}$, used in place of a simple count ratio.
Q33. Why do Naive Bayes implementations use log probabilities?
Multiplying many small probabilities can underflow to 0 on a computer; $\log P(C) + \sum \log P(x_i\mid C)$ turns the product into a sum, which is numerically stable and gives the same ranking of classes.
