Q1. What are the different types of machine learning?

Unit I · 8 marks · Name each type, say what feedback it uses, give one example each; draw the type tree first.

Definition: Machine learning is divided into types based on the feedback available to the learner: supervised learning uses labelled data $(x, y)$, unsupervised learning finds structure in unlabelled data ($x$ only), reinforcement learning learns from reward signals through trial and error, and semi-supervised learning mixes a small labelled set with a large unlabelled one.
  • Supervised learning: needs a teacher - every training example has the correct answer $(x,y)$. Category output → classification (spam/not spam); number output → regression (house price). Algorithms: KNN, decision tree, naive Bayes, logistic regression, SVM, linear regression.
  • Unsupervised learning: only $x$, no labels. Tasks: clustering (K-means - customer segmentation), dimensionality reduction (PCA), association rules (market basket, bread → butter).
  • Reinforcement learning: an agent takes actions in an environment, gets a reward, and learns a policy maximising cumulative reward, e.g. a maze robot or AlphaGo.
  • Semi-supervised learning: a few labelled examples plus many unlabelled ones - used when labelling is expensive (e.g. a few hundred labelled scans, thousands unlabelled).
  • Feedback timing differs: supervised gets an answer every time, unsupervised gets none, reinforcement often gets a delayed reward.
  • Exploration vs exploitation is unique to RL: try a new action to learn, or use the best known action to earn reward.

Q3. What are the various issues in machine learning?

Unit I · 8 marks · Give Mitchell's six research questions first, then the practical, day-to-day problems.

Definition: Issues in machine learning are the fundamental questions (which algorithm, how much data, what prior knowledge, which experience, what function, what representation) and practical problems (data quality, overfitting, bias, interpretability, computation) that affect how well a learner generalizes.
  • Algorithms: which algorithms learn general target functions from specific examples, and when do they converge?
  • Amount of training data: how much is sufficient; how does confidence relate to the amount of experience?
  • Prior knowledge: when and how can prior knowledge guide generalization, even if only approximately correct?
  • Choosing training experience: what is the best strategy for picking the next training example?
  • Reducing to function approximation: what functions should be learned, and can this be automated?
  • Altering representation: how can the learner automatically improve its own representation?
  • Practical issues: data quality (noise, missing values), overfitting / underfitting, bias and fairness, interpretability of black-box models, computation cost, privacy, and concept drift (accuracy drops as real-world data changes).

Q4. Explain data representations in machine learning (numerical and graph).

Unit I · 8 marks · Cover both halves - numeric feature vectors AND graphs - and end on the comparison table.

Definition: Numerical representation expresses each example as a feature vector $x = (x_1, \ldots, x_d) \in \mathbb{R}^d$, stored for $n$ examples as an $n \times d$ feature matrix. A graph $G = (V, E)$ instead stores relationships: vertices $V$ are entities and edges $E$ are connections between pairs of them, directed or undirected, weighted or not.
  • Numeric feature vector: house → $x = (1200, 3, 5)$ for (area, rooms, age); $n$ houses give an $n \times 3$ matrix.
  • Label encoding gives each category one integer (good for ordered categories); one-hot encoding gives one 0/1 column per category (no false order).
  • Feature scaling: min-max $x' = \dfrac{x-x_{min}}{x_{max}-x_{min}}$ gives $[0,1]$; z-score $z = \dfrac{x-\mu}{\sigma}$ gives mean 0, std 1.
  • Images flatten to a pixel-value vector (a $28\times28$ grayscale image → 784 features); text becomes a bag-of-words count vector.
  • Graph: node = entity, edge = relation; weighted edges carry a number; undirected (friendship) vs directed (following).
  • Adjacency matrix: $V \times V$ table, symmetric for undirected graphs, space $O(V^2)$, edge check $O(1)$ - best for dense graphs. Adjacency list: neighbours per node, space $O(V+E)$ - best for sparse graphs.
  • Uses of graphs in ML: social networks (link prediction), recommendation (user-item graph), knowledge graphs, molecules, road networks, fraud rings.

Q5. Explain linear regression with an example.

Unit II · 8 marks · Definition, least-squares formulas, then fit a line to a small dataset and predict a new value.

Definition: Linear regression is a supervised regression method that models a continuous output as a linear function of the input, $\hat{y} = \beta_0 + \beta_1 x$, with $\beta_0$ (intercept) and $\beta_1$ (slope) found by the least squares method - minimising the sum of squared errors.
  • Model: $y = \beta_0 + \beta_1 x + \varepsilon$; $\beta_0$ = value when $x=0$, $\beta_1$ = change in $y$ per unit $x$.
  • Residual $e_i = y_i - \hat{y}_i$; least squares minimises $SSE = \sum e_i^2$.
  • $$\beta_1 = \frac{\sum (x_i-\bar{x})(y_i-\bar{y})}{\sum (x_i-\bar{x})^2}, \qquad \beta_0 = \bar{y} - \beta_1 \bar{x}$$
  • $R^2 = 1 - \dfrac{SSE}{SST}$: fraction of variance explained (1 = perfect fit); MSE $=SSE/n$.
  • Only captures a linear relationship and is sensitive to outliers (squared error).
  • Applications: house price, sales forecasting, marks from study hours, crop yield from rainfall.
Worked example (computed in Python) · $x$ = study hours, $y$ = marks: (1,35) (2,40) (3,50) (4,55) (5,65)
$\bar{x} = \dfrac{15}{5}=3$, $\bar{y}=\dfrac{245}{5}=49$; $\sum(x-\bar{x})(y-\bar{y}) = 75$, $\sum(x-\bar{x})^2 = 10$
$\beta_1 = \dfrac{75}{10} = 7.5$; $\beta_0 = 49 - 7.5 \times 3 = 26.5$ → $\hat{y} = 7.5x + 26.5$
Predict $x=6$ study hours: $\hat{y} = 7.5 \times 6 + 26.5 = 71.5$
$\hat{y} = 7.5x + 26.5$; predicted marks for 6 study hours $= 71.5$
Mnemonic M-S-I-P: Means, Slope, Intercept, Predict.
If it comes as 4 marks: write the definition, the two formulas for $\beta_1$/$\beta_0$, and the worked example up to the prediction (skip $R^2$/MSE).
Quick recall $\beta_1$ from the sums, then $\beta_0 = \bar{y}-\beta_1\bar{x}$; least squares minimises $SSE$; $R^2 = 1-SSE/SST$.

Q7. What is a hypothesis function?

Unit II · 8 marks (small topic - write it precisely and link it to the cost function and hypothesis space).

Definition: The hypothesis function $h(x)$ is the function a learning algorithm uses to map an input $x$ to a predicted output. For linear regression: $$h(x) = \beta_0 + \beta_1 x$$ For logistic regression: $$h(x) = \sigma(\beta_0 + \beta_1 x) = \frac{1}{1 + e^{-(\beta_0 + \beta_1 x)}}$$
  • $h$ is one candidate function; the hypothesis space $H$ is the set of ALL candidate functions the learner could choose.
  • Learning = searching $H$ for the $h$ that best fits the training data (Mitchell's "learning as search" perspective).
  • The hypothesis is only a guess - how good it is is measured separately by the cost function $J$; training changes $h$'s parameters to reduce $J$.
  • Linear regression example: $\beta_0=2.2,\ \beta_1=0.6$, so $h(6)=2.2+0.6\times6=5.8$ - the model's predicted score for $x=6$.
  • Logistic regression example: $\beta_0=-4,\ \beta_1=1$, $x=5$ hours → $h(5)=\sigma(1)=0.7311 \ge 0.5$ → predicted class Pass.
  • The target function is the true, usually unknown, relationship; $h$ is only an approximation of it.

Q8. Explain logistic regression.

Unit II · 8 marks · Sigmoid formula, decision boundary at p = 0.5, and a worked pass/fail example.

Definition: Logistic regression is a supervised classification method that models the probability of the positive class as $$p = \sigma(z) = \frac{1}{1 + e^{-z}}$$ where $z = \beta_0 + \beta_1 x$, and assigns class 1 when $p \ge 0.5$.
  • Sigmoid $\sigma(0)=0.5$, $\sigma(+\infty)\to1$, $\sigma(-\infty)\to0$.
  • Log-odds (logit): $\ln\dfrac{p}{1-p}=z$ - the model is linear in the log-odds.
  • Decision boundary: $p=0.5$ exactly where $z=0$, i.e. $\beta_0+\beta_1x=0$ → a straight line/hyperplane.
  • Threshold need not be 0.5 - disease screening may use 0.3 to catch more true cases (fewer misses, more false alarms).
  • Log-loss $L=-\frac{1}{n}\sum[y_i\log\hat{y}_i+(1-y_i)\log(1-\hat{y}_i)]$; minimising it is the same as Maximum Likelihood Estimation (MLE).
  • Multi-class extension: one-vs-rest or softmax logistic regression.

Q9. Explain ensemble learning.

Unit II · 8 marks · Define it, explain bagging vs boosting, and show why combining classifiers raises accuracy.

Definition: Ensemble learning combines the predictions of multiple base models (weak learners) to produce a single prediction more accurate and stable than any individual model.
  • Why it works: different models make different mistakes; combining them cancels many errors.
  • Bagging (Bootstrap Aggregating): bootstrap samples, models trained in parallel, equal-weight vote/average; mainly cuts variance. Example: Random Forest.
  • Boosting: models trained sequentially, each new one focuses on the previous ones' errors; mainly cuts bias. Example: AdaBoost, Gradient Boosting.
  • Stacking: different kinds of base models feed a second-level meta-learner that learns how to combine them.
  • Hard voting = majority label wins; soft voting = average predicted probabilities, pick the highest.
  • Condition: base models must be better than random guessing and reasonably diverse.

Q10. Differentiate between classification and regression.

Unit I · 8 marks · State both definitions, then the difference table is the main content the examiner wants.

Definition: Both are supervised learning tasks that learn $f(x) \to y$ from labelled examples. Classification predicts a discrete class label (spam / not spam); regression predicts a continuous number (house price).
  • Classification asks "which class?" (binary: spam/not spam; multi-class: digit 0-9). Regression asks "how much / how many?".
  • A discriminant is the rule/function used to assign a class, e.g. IF Score1+Score2 $\ge 60$ THEN Pass ELSE Fail; two different discriminants can fit ALL the training rows and still disagree on a new point.
  • General regression model: $y = f(x,\theta)$, e.g. car $\text{Price} = a_0+a_1\!\cdot\!\text{Age}+a_2\!\cdot\!\text{Distance}+a_3\!\cdot\!\text{Weight}$.
  • Classification algorithms: KNN, decision tree, naive Bayes, logistic regression, SVM. Regression algorithm: linear regression.

Q11. What are outliers? Explain their types and detection.

Unit II · 8 marks · Definition, three types, IQR/z-score detection, then the worked numerical.

Definition: An outlier is a data point that differs significantly from the other observations in a dataset - caused by a measurement/entry error, or a genuine but rare event.
  • Types: global / point (far from all data, e.g. age = 250), contextual (odd only in context, e.g. 35°C is normal in May, not January), collective (a group is odd together, e.g. many small transfers in one minute).
  • IQR method: $IQR=Q_3-Q_1$; outlier if value $\lt Q_1-1.5\cdot IQR$ or $\gt Q_3+1.5\cdot IQR$. Robust - quartiles are not moved by the outlier.
  • Z-score method: $z=\dfrac{x-\mu}{\sigma}$; outlier if $|z|\gt3$. Assumes roughly normal data; can be fooled by masking (the outlier inflates $\sigma$, shrinking its own $z$).
  • Effects: pulls the mean, inflates variance, tilts a regression line, distorts distance-based methods (KNN, K-means).
Worked example (computed in Python) · marks: 12, 14, 15, 15, 16, 17, 18, 19, 20, 62
Sorted, $n=10$. Median $=\dfrac{16+17}{2}=16.5$. Lower half ⇒ $Q_1=15$; upper half ⇒ $Q_3=19$
$IQR=19-15=4$; $1.5\times IQR=6$; lower fence $=15-6=9$; upper fence $=19+6=25$
$62\gt25$ ⇒ 62 is an outlier. Z-check: $\mu=20.8,\sigma=13.92$, $z(62)=\dfrac{62-20.8}{13.92}=2.96$

Q12. Define the cost function and derive it for linear regression.

Unit II · 8 marks · State J, explain why it is squared, then do the calculus derivation step by step - this is the LaTeX-heavy answer.

Definition: A cost function $J(\beta_0,\beta_1)$ measures the average error of the hypothesis over all $m$ training examples: $$J(\beta_0,\beta_1) = \frac{1}{2m}\sum_{i=1}^{m} \big(h(x_i) - y_i\big)^2$$ Learning means finding the $\beta_0, \beta_1$ that minimise $J$.
  • Why square? Positive and negative errors cannot cancel; big errors are punished more; the result is a smooth, differentiable bowl.
  • Why $1/2$? Convenience only - the 2 from differentiating the square cancels it; the minimising $\beta_0,\beta_1$ are unchanged.
  • $J$ for linear regression is convex (one bowl, one minimum) - gradient descent cannot get stuck in a wrong valley.
  • Gradient descent update (when there is no closed form): $$\beta_0 := \beta_0 - \alpha \cdot \frac{1}{m}\sum (h(x_i)-y_i), \qquad \beta_1 := \beta_1 - \alpha \cdot \frac{1}{m}\sum (h(x_i)-y_i)\cdot x_i$$
  • For logistic regression, MSE would be non-convex, so log loss is used instead (still minimised the same gradient-descent way).
Derivation
Step 1. $$J(\beta_0,\beta_1) = \frac{1}{2m}\sum (\beta_0 + \beta_1 x_i - y_i)^2$$
Step 2. Partial derivative w.r.t. $\beta_0$ (the 2 cancels the $1/2$): $$\frac{\partial J}{\partial \beta_0} = \frac{1}{m}\sum (\beta_0 + \beta_1 x_i - y_i)$$
Step 3. Partial derivative w.r.t. $\beta_1$ (inner derivative is $x_i$): $$\frac{\partial J}{\partial \beta_1} = \frac{1}{m}\sum (\beta_0 + \beta_1 x_i - y_i) \cdot x_i$$
Step 4. At the minimum both are 0. From $\dfrac{\partial J}{\partial \beta_0}=0$: $\sum y_i = m\beta_0+\beta_1\sum x_i$ ⇒ $$\beta_0 = \bar{y} - \beta_1 \bar{x}$$
Step 5. From $\dfrac{\partial J}{\partial \beta_1}=0$: $\sum x_iy_i = \beta_0\sum x_i + \beta_1\sum x_i^2$
Step 6. Substitute $\beta_0=\bar{y}-\beta_1\bar{x}$ and simplify:
$$\beta_1 = \frac{\sum (x_i-\bar{x})(y_i-\bar{y})}{\sum (x_i-\bar{x})^2}, \qquad \beta_0 = \bar{y} - \beta_1 \bar{x}$$
Mnemonic H-C-G = Hypothesis guesses, Cost grades, Gradient corrects.
If it comes as 4 marks: write the definition of $J$, why it is squared, and Steps 1-4 of the derivation up to $\beta_0=\bar{y}-\beta_1\bar{x}$ (skip the full $\beta_1$ simplification).
Quick recall $J=\frac{1}{2m}\sum(h-y)^2$; set both partial derivatives to 0 to get $\beta_1=\frac{\sum(x_i-\bar{x})(y_i-\bar{y})}{\sum(x_i-\bar{x})^2}$, $\beta_0=\bar{y}-\beta_1\bar{x}$.

Q13. Using KNN, find the class of a new point (worked numerical).

Unit II · 8 marks · Compute distance to every training point, sort, take the k nearest, and vote - box the final class.

Definition: K-Nearest Neighbours is a non-parametric, instance-based supervised algorithm that classifies a new point by the majority class of its k closest training points, closeness measured by a distance such as Euclidean distance.
  • Algorithm: compute distance to every training point → sort ascending → take the $k$ nearest → majority vote of their classes.
  • Euclidean distance (2D): $d=\sqrt{(x_1-x_2)^2+(y_1-y_2)^2}$.
  • Odd $k$ avoids ties for two classes; feature scaling is compulsory since KNN is purely distance-based.
  • Lazy learner: no training phase, all work happens at prediction time.

1-mark questions

Q1. Define machine learning (Mitchell).
A program learns from experience E with respect to tasks T and performance measure P if its performance at T, measured by P, improves with E.
Q2. What is a well-posed learning problem? Give T, P, E for checkers.
A learning problem with clearly identified task, performance measure and experience. Checkers: T = playing checkers, P = % games won, E = games played against itself.
Q3. Differentiate traditional programming and ML.
Traditional: data + hand-written rules → output. ML: data + example outputs → learned rules (model), which then predict outputs for new data.
Q4. How are AI, ML and DL related?
$\text{DL} \subset \text{ML} \subset \text{AI}$. AI = intelligent behaviour by machines; ML = AI that learns from data; DL = ML using multi-layer neural networks.
Q5. What is overfitting?
The model fits training data including noise, giving very low training error but high test error, i.e. poor generalization. Caused by high variance.
Q6. Define generalization.
The ability of a learned model to perform well on new, unseen data drawn from the same distribution as the training data.
Q7. What is a hypothesis space?
The set $H$ of all candidate functions a learner can choose from; learning is a search through $H$ for the hypothesis that best fits the data.
Q8. List the four choices in designing a learning system.
(1) Training experience, (2) target function, (3) representation of target function, (4) function approximation (learning) algorithm.
Q9. List any four issues in machine learning.
Choice of algorithm, amount of training data, use of prior knowledge, choice of representation (also: data quality, overfitting, bias, interpretability).
Q10. What is unsupervised learning? Give two tasks.
Learning patterns from unlabelled data. Tasks: clustering (K-means) and dimensionality reduction (PCA); also association rules.
Q11. Define agent, state, action and reward in RL.
Agent = learner that acts; state = current situation; action = choice made by the agent; reward = numeric feedback from the environment for that action.
Q12. What is semi-supervised learning?
Learning from a small labelled set together with a large unlabelled set, used when labelling data is expensive.
Q13. Differentiate label encoding and one-hot encoding.
Label encoding gives each category one integer (Blue 0, Green 1, Red 2). One-hot gives one 0/1 column per category, avoiding false order.
Q14. Why is KNN called a lazy learner?
It builds no model during training; it only stores the data and does all computation (distances, voting) at prediction time.
Q15. Write the Euclidean and Manhattan distance formulas.
Euclidean $d = \sqrt{\sum (p_i - q_i)^2}$; Manhattan $d = \sum |p_i - q_i|$.
Q16. Why is an odd value of k preferred in KNN?
For two-class problems an odd k prevents a tie in the majority vote.
Q17. Define entropy.
Entropy measures impurity of a set: $H(S) = -\sum p_i \log_2 p_i$. It is 0 for a pure set and 1 for an equal two-class split.
Q18. What is information gain?
Reduction in entropy after splitting on attribute $A$: $IG(S,A) = H(S) - \sum_v \frac{|S_v|}{|S|} H(S_v)$. ID3 splits on the attribute with the highest gain.
Q19. Define Gini index.
$Gini = 1 - \sum p_i^2$; an impurity measure used by CART; 0 means pure, lower weighted Gini means a better split.
Q20. What is pruning?
Removing branches of a decision tree that add little accuracy, to reduce overfitting. Pre-pruning stops growth early; post-pruning cuts a fully grown tree.
Q21. State Bayes' theorem.
$P(C \mid X) = \dfrac{P(X \mid C)\,P(C)}{P(X)}$: posterior = likelihood × prior / evidence.
Q22. Why is Naive Bayes called "naive"?
It assumes all features are conditionally independent of each other given the class, which is rarely true in practice.
Q23. What is Laplace smoothing?
Adding 1 to every count, $P = \dfrac{\text{count} + 1}{n + k}$, so that an unseen feature value does not make the whole probability zero.
Q24. What are support vectors?
Training points lying on the margin boundaries $w^T x + b = \pm 1$; they alone determine the SVM hyperplane.
