2.1 Supervised learning: regression vs classification

A teacher gives questions WITH answers; the student learns the pattern and then answers new questions. (answer key ke saath padhai)

Definition: Supervised learning is learning a function f that maps an input x to an output y from a training set of labelled pairs (x, y), so that f can predict y for new, unseen x.
  • Features (x) = input attributes; label / target (y) = the known answer.
  • Regression: y is continuous, e.g. predicting a flat's price or tomorrow's temperature.
  • Classification: y is a category, e.g. spam / not spam, pass / fail. (dabba chunna)
  • Training set is used to fit the model; test set checks it on unseen data.
  • Overfitting = model memorises training data and fails on new data; underfitting = model too simple to capture the pattern.
  • Note: KNN and decision trees can also do regression (average of neighbours / leaf mean); SVM has a regression form (SVR).

2.2 Nearest-Neighbours (K-Nearest Neighbours, KNN)

"Tell me who your neighbours are, I'll tell you who you are." A new student in a hostel is guessed to like cricket if most of the nearest roommates do. (jaisa padosi, waisa tum)

Definition: K-Nearest Neighbours is a non-parametric, instance-based supervised algorithm that classifies a new point by the majority class of its k closest training points (for regression: the average of their values), closeness measured by a distance such as Euclidean distance.

Distance formulas (points p = (x1, y1), q = (x2, y2))

  • Euclidean distance = √[(x1 − x2)² + (y1 − y2)²] (straight-line distance). In n dimensions: √Σ(pi − qi)².
  • Manhattan distance = |x1 − x2| + |y1 − y2| (city-block distance, like walking along Chandigarh's grid of sectors). (gali-gali chal ke)
  • Minkowski = (Σ|pi − qi|^p)^(1/p); p = 1 gives Manhattan, p = 2 gives Euclidean.

Key points

  • Choosing k: small k (k = 1) is noisy and overfits; large k smooths too much and underfits. Pick k by trying values on validation data; a common rule of thumb starts near √n.
  • Odd k for two classes avoids a tie in voting (k = 3, 5, 7).
  • Feature scaling is compulsory: a feature measured in lakhs (salary) swamps one measured in years (age). Use min-max normalisation or standardisation first.
  • Lazy learner: no training phase, it just stores data; all work happens at prediction time, so prediction is slow for big data. (exam ke din hi padhta hai)
  • Weighted KNN: closer neighbours get larger vote weight (e.g. 1/distance).

2.3 Decision Trees (ID3, entropy, information gain, Gini)

A decision tree is a game of "20 questions": ask the most useful question first, then keep asking until the answer is clear. (sawaal pe sawaal, jawab tak)

Definition: A decision tree is a tree-shaped supervised model in which each internal node tests an attribute, each branch is an outcome of the test, and each leaf node holds a class label (or a value, for regression). Prediction follows one path from root to leaf.

Formulas

  • Entropy (impurity, disorder): H(S) = − Σ pi log₂ pi, where pi = fraction of class i. H = 0 for a pure set; H = 1 for a 50-50 two-class set. (kitna ghalmel hai)
  • Information gain: Gain(S, A) = H(S) − Σ (|Sv| / |S|) · H(Sv). ID3 picks the attribute with maximum gain.
  • Gini index (used by CART): Gini(S) = 1 − Σ pi². 0 = pure, 0.5 = worst for two classes. CART picks the split with the lowest weighted Gini and builds binary trees.
  • ID3 (Quinlan) uses information gain; C4.5 improves it with gain ratio and handles numeric attributes; CART uses Gini.

Overfitting and pruning

  • Overfitting: a fully grown tree keeps splitting until every leaf is pure, learning noise; it scores well on training data but poorly on test data.
  • Pre-pruning (early stopping): stop growing when depth limit, minimum samples per node, or minimum gain is reached.
  • Post-pruning: grow the full tree, then remove sub-trees that do not improve accuracy on validation data (e.g. reduced-error pruning, cost-complexity pruning in CART). (faltu shaakhein kaat do)

2.4 Naive Bayes classifier

A doctor guesses the disease by combining "how common is it" with "how typical are these symptoms for it". (pehle ka andaaza + naya saboot)

Definition: Naive Bayes is a probabilistic classifier based on Bayes' theorem that assumes all features are conditionally independent given the class; it predicts the class with the highest posterior probability P(C | X).
  • Bayes' theorem: P(C | X) = P(X | C) · P(C) / P(X).
  • Prior P(C): belief about the class before seeing features.
  • Likelihood P(X | C): how probable the features are if the class is C.
  • Posterior P(C | X): updated probability after seeing features. Evidence P(X) is the same for every class, so it can be ignored when comparing.
  • Conditional independence ("naive" assumption): P(x1, x2, …, xn | C) = P(x1 | C) · P(x2 | C) ⋯ P(xn | C). Rarely true in real life, yet the classifier works well. (sab features apne-apne, bhole-bhaale)
  • Laplace smoothing: if any count is 0, the whole product becomes 0. Use P(xi | C) = (count + 1) / (nC + k), where k = number of values of that feature.

2.5 Linear models: Linear Regression

Fit the straightest ruler line through scattered dots so that the dots are, on average, as close to the line as possible. (beech se seedhi line)

Definition: Linear regression is a supervised regression method that models a continuous output as a linear function of the input, y = b₀ + b₁x, with b₀ (intercept) and b₁ (slope) found by the least squares method, i.e. minimising the sum of squared errors.
  • Model: y = b₀ + b₁x + ε; b₀ = intercept (value when x = 0), b₁ = slope (change in y per unit x), ε = error.
  • Residual e = y − ŷ. Least squares chooses b₀, b₁ to minimise SSE = Σ(y − ŷ)².
  • MSE = SSE / n. R² = 1 − SSE/SST, where SST = Σ(y − ȳ)²; R² = fraction of variance explained (1 = perfect fit).
  • Gradient descent (iterative alternative): (1) start with b₀ = b₁ = 0; (2) compute gradient of MSE w.r.t. each coefficient; (3) update b ← b − α·gradient (α = learning rate) and repeat until the error stops falling.
  • Multiple linear regression: y = b₀ + b₁x₁ + b₂x₂ + … + bₙxₙ (many inputs, e.g. price from area, rooms, floor).
  • Assumptions: linear relation, independent errors, constant error variance, no strong multicollinearity.

2.6 Linear models: Logistic Regression

Take the linear score, squash it into a probability between 0 and 1, then say "Yes" if it is above 0.5. (score ko 0-1 mein dabao)

Definition: Logistic regression is a supervised classification method that models the probability of the positive class as p = σ(z) = 1 / (1 + e^(−z)), where z = w₀ + w₁x₁ + … + wₙxₙ, and assigns class 1 when p ≥ 0.5.
  • Sigmoid σ(z) = 1/(1 + e^(−z)): σ(0) = 0.5, σ(+∞) → 1, σ(−∞) → 0.
  • Log-odds (logit): ln[p / (1 − p)] = z = w₀ + w₁x. The model is linear in the log-odds, hence a "linear model".
  • Decision boundary: p = 0.5 exactly where z = 0, i.e. w₀ + w₁x₁ + … = 0 → a straight line / hyperplane.
  • Log-loss (binary cross-entropy): L = −[y ln p + (1 − y) ln(1 − p)]; weights are learned by minimising it with gradient descent (no closed form).
  • Multi-class: one-vs-rest or softmax (multinomial) logistic regression.

2.7 Linear models: Support Vector Machines (SVM)

Separate two groups with the widest possible road, not just any line; the points touching the road's edges decide where it goes. (sabse chaudi sadak beech mein)

Definition: A Support Vector Machine is a supervised classifier that finds the hyperplane w·x + b = 0 separating two classes with the maximum margin; the training points lying on the margin boundaries are called support vectors.
  • Hyperplane: w·x + b = 0 (a line in 2D, plane in 3D). w = normal (perpendicular) vector, b = bias.
  • Margin: distance between the planes w·x + b = +1 and w·x + b = −1, equal to 2/‖w‖. Maximising margin = minimising ½‖w‖².
  • Support vectors: points with yi(w·xi + b) = 1, lying on the margin boundary; only they decide the hyperplane. Removing other points does not change it.
  • Hard margin: no point allowed inside the margin; works only for perfectly separable data.
  • Soft margin: slack variables ξi allow some violations; minimise ½‖w‖² + C Σξi. C large = few violations, narrow margin (risk overfit); C small = wide margin, more violations. (C = galti ki saza)
  • Prediction: class = sign(w·x + b). Multi-class via one-vs-one or one-vs-rest.

2.8 Nonlinearity and Kernel Methods

Coins mixed on a table cannot be split by one straight stick, but lift the heavy ones up into the air and a flat sheet separates them. (upar utha ke alag karo)

Definition: Kernel methods handle non-linearly separable data by implicitly mapping inputs to a higher-dimensional feature space φ(x) where a linear separator exists; a kernel function K(x, z) = φ(x)·φ(z) computes the dot product in that space without computing φ explicitly (the kernel trick).

Why a linear boundary fails

  • XOR problem: points (0,0), (1,1) in class 0 and (0,1), (1,0) in class 1 cannot be split by any single straight line.
  • Circular data: one class inside a circle, the other in a ring around it; boundary must be a circle, not a line.
  • Fix: add features (x², xy, …) so that the data becomes linearly separable in the new space (Cover's theorem idea: higher dimension makes separation more likely).
  • Problem: explicit mapping to very high (even infinite) dimension is costly. Kernel trick: algorithms like SVM only need dot products xi·xj, so replace them by K(xi, xj). (bina upar gaye, upar wala hisaab)
  • A valid kernel must be symmetric and positive semi-definite (Mercer's condition).

2.10 Short answers (1.5 marks)

Q1. Differentiate regression and classification.
Regression predicts a continuous value (e.g. price); classification predicts a discrete class label (e.g. spam / not spam). Linear regression vs logistic regression is the standard pair.
Q2. Why is KNN called a lazy learner?
It builds no model during training; it only stores the data and does all computation (distances, voting) at prediction time.
Q3. Write the Euclidean and Manhattan distance formulas.
Euclidean d = √Σ(pi − qi)²; Manhattan d = Σ|pi − qi|.
Q4. Why is an odd value of k preferred in KNN?
For two-class problems an odd k prevents a tie in the majority vote.
Q5. Define entropy.
Entropy measures impurity of a set: H(S) = −Σ pi log₂ pi. It is 0 for a pure set and 1 for an equal two-class split.
Q6. What is information gain?
Reduction in entropy after splitting on attribute A: Gain(S, A) = H(S) − Σ(|Sv|/|S|)H(Sv). ID3 splits on the attribute with the highest gain.
Q7. Define Gini index.
Gini = 1 − Σ pi²; an impurity measure used by CART; 0 means pure, lower weighted Gini means a better split.
Q8. What is pruning?
Removing branches of a decision tree that add little accuracy, to reduce overfitting. Pre-pruning stops growth early; post-pruning cuts a fully grown tree.
Q9. State Bayes' theorem.
P(C | X) = P(X | C) · P(C) / P(X): posterior = likelihood × prior / evidence.
Q10. Why is Naive Bayes called "naive"?
It assumes all features are conditionally independent of each other given the class, which is rarely true in practice.
Q11. What is Laplace smoothing?
Adding 1 to every count, P = (count + 1)/(n + k), so that an unseen feature value does not make the whole probability zero.
Q12. What is the least squares method?
Choosing regression coefficients that minimise the sum of squared residuals Σ(y − ŷ)²; gives b₁ = Σ(x−x̄)(y−ȳ)/Σ(x−x̄)², b₀ = ȳ − b₁x̄.
Q13. What does R² indicate?
R² = 1 − SSE/SST, the proportion of variance in y explained by the model; closer to 1 means better fit.
Q14. Write the sigmoid function and its role.
σ(z) = 1/(1 + e^(−z)); it converts the linear score of logistic regression into a probability between 0 and 1.
Q15. What are support vectors?
Training points lying on the margin boundaries w·x + b = ±1; they alone determine the SVM hyperplane.
Q16. Define margin in SVM.
The distance between the two margin boundaries on either side of the hyperplane, equal to 2/‖w‖; SVM maximises it.
Q17. What is the kernel trick?
Replacing dot products xi·xj with a kernel K(xi, xj) = φ(xi)·φ(xj), so a linear algorithm works in a higher-dimensional space without computing φ explicitly.
Q18. Name any four kernel functions.
Linear x·z; polynomial (x·z + c)^d; RBF/Gaussian exp(−γ‖x − z‖²); sigmoid tanh(κx·z + c).
