1.5 Java Operators and Precedence

Operators are symbols that direct the JVM to perform specific mathematical, logical, or bitwise computations. (operator calculation karvata hai)

Definition: An operator is a special symbol that operates on one, two, or three operands to perform calculations and produce a result value.
Operator CategorySymbolsDescription & Behavior
Arithmetic+, -, *, /, %Addition, subtraction, multiplication, division, modulus (remainder).
Unary / Increment++, --, +, -, !, ~Pre-increment (++x: increment first), Post-increment (x++: use then increment).
Relational==, !=, >, <, >=, <=Compares two operands; returns boolean result.
Logical&&, ||, !Short-circuit AND (&&), short-circuit OR (||), logical NOT.
Bitwise & Shift&, |, ^, ~, <<, >>, >>>AND, OR, XOR, NOT, left-shift, signed right-shift, unsigned right-shift.
Assignment=, +=, -=, *=, /=, %=Assigns value to variable; compound assignment performs op then assigns.
Cast(type)Explicitly converts (type-casts) a value from one data type to another, e.g. (int) 9.8 gives 9.
Ternarycondition ? val1 : val2Shorthand if-else operator evaluating to val1 if true, val2 if false.
Type comparisoninstanceofChecks if an object is an instance of a specified class/interface.

Program: Demonstrating unary increment, bitwise AND, and ternary operator.

public class OperatorDemo {
    public static void main(String[] args) {
        int a = 10, b = 3;
        int pre = ++a;             // Pre-increment: a becomes 11, pre=11
        int post = b++;            // Post-increment: post=3, b becomes 4
        int bit = 5 & 3;           // Bitwise AND: 101 & 011 = 001 (1)
        int max = (a > b) ? a : b;  // Ternary operator
        System.out.println("pre=" + pre + ", post=" + post + ", bit=" + bit + ", max=" + max);
    }
}
pre=11, post=3, bit=1, max=11

The cast operator (type) is listed by many textbooks as its own operator category, distinct from arithmetic/relational/logical operators — it is the operator form of type casting. See the Data Types topic for the full widening/narrowing rules and hierarchy diagram.

Common mistake: Confusing && (short-circuit logical AND) with & (bitwise AND). && stops evaluating if the first condition is false.
Quick recall Pre-increment (++i) increments before value use; post-increment (i++) uses current value first. Ternary format: cond ? trueVal : falseVal.
