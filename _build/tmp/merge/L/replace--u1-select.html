1.7 Selection Statements (if, if-else, switch)

Selection statements branch code execution based on conditional true/false decisions or value matching. (conditional decision ke hisaab se rasta chuno)

Definition: Selection statements (decision-making statements) allow a program to choose between different execution paths based on the boolean result of a condition or discrete value match.
  • if statement: Executes block only if condition evaluates to true.
  • if-else statement: Executes if block when true, else block when false.
  • else-if ladder: Tests multiple conditions sequentially until one evaluates to true.
  • switch statement: Multi-way branch comparing an integer/char/String expression against multiple case values. Requires break to prevent fall-through.

Program: Selection using if-else and switch statements.

public class SelectionDemo {
    public static void main(String[] args) {
        int number = 15;
        if (number % 2 == 0) {
            System.out.println(number + " is Even");
        } else {
            System.out.println(number + " is Odd");
        }
        int day = 2;
        switch (day) {
            case 1: System.out.println("Monday"); break;
            case 2: System.out.println("Tuesday"); break;
            default: System.out.println("Other day");
        }
    }
}

The if-else-if ladder chains conditions top to bottom; the first condition that is true runs its block and skips the rest, and a final plain else catches every remaining case (grade computation is the classic example).

Program: Grading using an if-else-if ladder.

public class IfElseDemo {
    public static void main(String[] args) {
        int marks = 76;
        char grade;
        if (marks >= 90) {
            grade = 'A';
        } else if (marks >= 80) {
            grade = 'B';
        } else if (marks >= 70) {
            grade = 'C';
        } else if (marks >= 60) {
            grade = 'D';
        } else if (marks >= 50) {
            grade = 'E';
        } else {
            grade = 'F';
        }
        System.out.println("Grade is " + grade);
    }
}

Program: switch over all seven days of the week, with a default for invalid input.

public class SwitchDemo {
    public static void main(String[] args) {
        int day = 2;
        switch (day) {
            case 1: System.out.println("Sunday"); break;
            case 2: System.out.println("Monday"); break;
            case 3: System.out.println("Tuesday"); break;
            case 4: System.out.println("Wednesday"); break;
            case 5: System.out.println("Thursday"); break;
            case 6: System.out.println("Friday"); break;
            case 7: System.out.println("Saturday"); break;
            default: System.out.println("Invalid day");
        }
    }
}
Monday
Quick recall if-else evaluates boolean expressions; switch matches discrete values. Always add break in switch cases.
