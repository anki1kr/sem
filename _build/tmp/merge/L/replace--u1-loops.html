1.8 Iteration & Jump Statements (for, while, do-while, break, continue)

Looping statements repeat a block of code until a specified condition becomes false. (jab tak condition true hai, tab tak chalao)

Definition: Iteration statements (loops) repeatedly execute a statement block as long as a loop termination condition remains true.
  • for loop: Entry-controlled loop ideal when the number of iterations is known in advance (initialization; condition; update).
  • while loop: Entry-controlled loop that tests condition before executing the loop body.
  • do-while loop: Exit-controlled loop that executes the body at least once before testing condition.
  • Enhanced for loop (for-each): Simplifies traversing collections and arrays without manual index tracking. Syntax: for (Type var : array) { ... }.
  • Labeled for loop: A label: placed before a loop lets a break or continue inside a NESTED loop target the labelled (usually outer) loop directly, instead of only the innermost one. Syntax: label: for (init; cond; update) { ... }.
  • break: Immediately terminates the innermost loop or switch block.
  • continue: Skips the rest of the current iteration and jumps to the next loop evaluation step.

Program: Demonstrating for loop, break/continue jump statements, and do-while loop.

public class LoopDemo {
    public static void main(String[] args) {
        int sum = 0;
        for (int i = 1; i <= 5; i++) {
            if (i == 4) continue; // Skip i=4
            sum += i;
        }
        System.out.println("Sum = " + sum);
        int count = 1;
        do {
            System.out.print(count + " ");
            count++;
        } while (count <= 3);
        System.out.println();
    }
}

Jump statements in detail — break and continue alter the normal control flow of a loop: break immediately jumps to the statement right after the loop (ending it), while continue immediately jumps to the next iteration test, skipping only the rest of the current pass.

Program: break stops the loop completely once i reaches 5.

public class BreakDemo {
    public static void main(String[] args) {
        for (int i = 1; i <= 10; i++) {
            if (i == 5) {
                break;             // terminate the loop when i is 5
            }
            System.out.println(i);
        }
        System.out.println("Loop is over.");
    }
}

Program: a labelled break outer exits BOTH the outer and inner for loops in one step, the moment i==2 && j==2; a plain unlabelled break here would only have stopped the inner loop.

public class LabeledLoopDemo {
    public static void main(String[] args) {
        outer:
        for (int i = 1; i <= 3; i++) {
            for (int j = 1; j <= 3; j++) {
                if (i == 2 && j == 2) {
                    break outer;   // exits BOTH loops at once
                }
                System.out.println("i=" + i + ", j=" + j);

Classic loop-based programs — frequent lab/exam programs that use only loops, if-else, and operators already covered above. Each extracts digits with the same while (n > 0) { r = n % 10; ...; n = n / 10; } pattern and finishes with one comparison, so the same flowchart shape applies to both the Palindrome and Armstrong checks below.

Program 1: Fibonacci series — each term is the sum of the previous two.

public class Fibonacci {
    public static void main(String[] args) {
        int n1 = 0, n2 = 1, n3, count = 10;
        System.out.print(n1 + " " + n2);
        for (int i = 2; i < count; i++) {
            n3 = n1 + n2;
            System.out.print(" " + n3);
            n1 = n2;
            n2 = n3;
        }
        System.out.println();
    }
}

Program 2: Prime number check — a number is prime if no value from 2 up to (but not including) itself divides it evenly.

public class PrimeNum {
    public static void main(String[] args) {
        int num = 17;
        int flag = 0;
        for (int i = 2; i < num; i++) {
            if (num % i == 0) {
                System.out.println(num + " is not a prime number");
                flag = 1;
                break;
            }
        }
        if (flag == 0) {
            System.out.println(num + " is a prime number");
        }
    }
}
17 is a prime number

Program 3: Palindrome number check — reverse the digits with a while loop and compare the reversed value to the original.

public class PalindromeCheck {
    public static void main(String[] args) {
        int r, sum = 0, temp;
        int n = 454;
        temp = n;
        while (n > 0) {
            r = n % 10;
            sum = (sum * 10) + r;
            n = n / 10;
        }
        if (temp == sum) {
            System.out.println("Palindrome Number");
        } else {
            System.out.println("Not palindrome");
        }
    }
}

Program 4: Factorial using a simple for loop — fact is multiplied by every integer from 1 to num.

public class Factorial {
    public static void main(String[] args) {
        int i, fact = 1;
        int num = 5;
        for (i = 1; i <= num; i++) {
            fact = fact * i;
        }
        System.out.println("Factorial of " + num + " is: " + fact);
    }
}
Factorial of 5 is: 120

Program 5: Armstrong number check — a 3-digit Armstrong number equals the sum of the cubes of its own digits (1³+5³+3³ = 153).

public class ArmstrongNum {
    public static void main(String[] args) {
        int sum = 0, r, temp;
        int n = 153;
        temp = n;
        while (n > 0) {
            r = n % 10;
            sum = sum + (r * r * r);
            n = n / 10;
        }
        if (temp == sum) {
            System.out.println("Armstrong number");
        } else {
            System.out.println("Not a Armstrong Number");
        }
    }
}
