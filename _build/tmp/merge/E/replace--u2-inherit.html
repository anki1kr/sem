2.8 Inheritance, extends and super

A child inherits the family surname and property, and can add things of its own. (baap ka sab bete ko milta hai, beta apna bhi jod sakta hai)

Definition: Inheritance is the mechanism by which one class (subclass / child) acquires the fields and methods of another class (superclass / parent) using the extends keyword. It represents an IS-A relationship and provides code reusability.
  • Syntax: class Child extends Parent { ... }. A class can extend only one class.
  • Reusability: write common code once in the parent; children reuse it. (code dobara nahi likhna)
  • IS-A test: "Dog is an Animal" makes sense, so inheritance fits.
  • Child inherits non-private members; private members and constructors are not inherited.
  • Every class that extends nothing implicitly extends java.lang.Object, the root of all classes.
  • A final class (e.g. String) cannot be extended.

The super keyword has three uses:

UseSyntaxPurpose
Parent's variablesuper.valueWhen child has a field with the same name
Parent's methodsuper.show()Call parent version of an overridden method
Parent's constructorsuper(args)Initialise parent part; first line of child constructor
Mnemonic super V-M-C: Variable, Method, Constructor.
class Animal {                   // parent (super) class
    String name = "Animal";
    void eat() {
        System.out.println(name + " is eating");
    }
}

class Dog extends Animal {       // child (sub) class: Dog IS-A Animal
    Dog() {
        name = "Tommy";          // inherited field
    }
    void bark() {
        System.out.println(name + " is barking");
    }
}

public class SingleInherit {
    public static void main(String[] args) {
        Dog d = new Dog();
        d.eat();                 // inherited method
        d.bark();                // own method
    }
}
Tommy is eating
Tommy is barking

A child gets every non-private member of the parent automatically, with no re-typing. The class notes' own single-inheritance example shows this with a field instead of a method:

class Employee {
    int salary = 4000;
}

class Programmer extends Employee {
    int bonus = 1000;

    public static void main(String[] args) {
        Programmer p = new Programmer();
        System.out.println("Programmer salary is: " + p.salary);  // salary: inherited, not redeclared
        System.out.println("Bonus of programmer is: " + p.bonus);
    }
}
Programmer salary is: 4000
Bonus of programmer is: 1000
Common mistake: thinking a private field is "inherited but hidden, reachable somehow". It is not reachable from the child class at all, not even indirectly, unless the parent itself exposes it through a public/protected method.
Quick recall extends = inheritance = IS-A; super reaches parent's variable, method, constructor; Object is the root class.
