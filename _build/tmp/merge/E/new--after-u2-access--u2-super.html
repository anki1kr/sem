2.10 The super keyword

"super" is how a child calls back to its parent's house when its own copy of something is in the way. (khud ka hone par bhi, parent wala chahiye to super lagao)

Definition: super is a reference to the immediate parent class. It is used to access a field of the parent that the child has hidden, to call a method of the parent that the child has overridden, and to invoke a constructor of the parent.
  • super.variable: reaches the parent's field when the child has declared a field with the same name (field hiding, not overriding — fields are never overridden in Java).
  • super.method(): calls the parent's version of a method the child has overridden.
  • super(args): calls a constructor of the parent class; it must be the first statement of the child's constructor.
  • super always means the immediate parent, even in a longer chain (grandparent members need the parent to relay them).
Mnemonic super V-M-C: Variable, Method, Constructor.

(a) Accessing the parent's variable and calling the parent's method:

class Vehicle {
    int speed = 50;

    void message() {
        System.out.println("Welcome to Vehicle class");
    }
}

class Bike extends Vehicle {
    int speed = 100;               // hides Vehicle's speed, does not delete it

    void message() {                // overrides Vehicle's message()
        System.out.println("Welcome to Bike class");
    }

    void display() {
        System.out.println("Bike speed is: " + speed);              // own field
        System.out.println("Vehicle avg speed is: " + super.speed);  // parent field
        message();               // invoke local (overriding) method
        super.message();         // invoke parent method
    }
}

public class SuperFieldMethod {
    public static void main(String[] args) {
        Bike b = new Bike();
        b.display();
    }
}

(b) Invoking the parent's constructor with super():

class Vehicle {
    Vehicle() {
        System.out.println("Vehicle is created");
    }
}

class Car extends Vehicle {
    Car() {
        super();                  // invoke parent class constructor; must be first line
        System.out.println("Car is created");
    }

    public static void main(String[] args) {
        Car c = new Car();
    }
}
Vehicle is created
Car is created
Common mistake: forgetting that super() (or this()) must be the very first statement of a constructor. Even without writing it, the compiler silently inserts a no-argument super() as the first line, which is why the parent always finishes constructing before the child's own body runs.
Quick recall super.field → parent's hidden field; super.method() → parent's overridden method; super(args) → parent's constructor, must be first line.
