2.16 Interface and multiple inheritance

An interface is a contract, like a phone charging port standard: any company's phone that implements it must provide those pins. (interface = wada, class ko nibhana padega)

Definition: An interface is a reference type declared with the interface keyword that contains abstract methods (and constants) specifying what a class must do. A class uses implements to accept the contract and must provide bodies for all its abstract methods. A class can implement many interfaces, which is how Java achieves multiple inheritance.
  • Methods are public abstract by default; variables are public static final (constants).
  • No constructors, no object creation: new Camera() is an error.
  • Implementing methods must be declared public in the class.
  • Java 8 added default methods (with a body, e.g. volume()) and static methods in interfaces; Java 9 added private methods.
  • Multiple inheritance: class Smartphone implements Camera, MusicPlayer (Fig 2.20). A class can extend one class and implement many interfaces together: class A extends B implements X, Y.
  • An interface extends other interfaces, not implements them, and — unlike a class — it may extend more than one interface at a time.
  • A field inside an interface must be initialised at the point of declaration, since it is implicitly final and can never be assigned later: int MAX = 100;
  • If a class implements an interface but leaves even one abstract method without a body, that class itself must be declared abstract — the same rule that governs abstract classes (2.15).

Program: multiple inheritance through interfaces, with a default method.

interface Camera {
    void click();                        // public abstract by default
}

interface MusicPlayer {
    void play();
    default void volume() {              // Java 8 default method (has a body)
        System.out.println("Volume set to 50");
    }
}

class Smartphone implements Camera, MusicPlayer {   // multiple inheritance
    public void click() { System.out.println("Photo clicked"); }
    public void play()  { System.out.println("Song playing"); }
}

public class InterfaceDemo {
    public static void main(String[] args) {
        Smartphone s = new Smartphone();
        s.click();
        s.play();
        s.volume();
        Camera c = s;  c.click();        // interface-type reference
    }
}

Program: an interface can declare constants (implicitly public static final), used directly by an implementing class or through the interface name.

interface Constants {
    int MAX = 100;                // implicitly public static final; must be initialised
}

class Config implements Constants {
    void show() {
        System.out.println("MAX = " + MAX);   // used directly, like an inherited constant
    }
}

public class InterfaceConstants {
    public static void main(String[] args) {
        Config c = new Config();
        c.show();
        System.out.println("Direct access: " + Constants.MAX);   // through the interface name
    }
}
MAX = 100
Direct access: 100

Program: interface extending interfaces — Amphibious extends both Flyable and Swimmable (Fig 2.70); a class implementing Amphibious must supply a body for all three abstract methods.

interface Flyable {
    void fly();
}

interface Swimmable {
    void swim();
}

interface Amphibious extends Flyable, Swimmable {   // interface extending TWO interfaces
    void walk();
}

class Duck implements Amphibious {                  // must implement all THREE abstract methods
    public void fly()  { System.out.println("Duck flies"); }
    public void swim() { System.out.println("Duck swims"); }
    public void walk() { System.out.println("Duck walks"); }
}

public class InterfaceExtendsDemo {
    public static void main(String[] args) {
        Duck d = new Duck();
        d.fly();
        d.swim();
        d.walk();
    }
}
