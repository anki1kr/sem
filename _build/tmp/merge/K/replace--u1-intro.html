1.1 Introduction to Java, JDK, JRE and JVM

Java was built so code written on a Windows PC runs unchanged on Linux or Mac. (ek baar likho, har jagah chalao)

Definition: Java is a high-level, object-oriented, class-based, platform-independent programming language created by James Gosling at Sun Microsystems in 1995.
  • JDK (Java Development Kit): Complete software bundle needed to write and compile Java programs. Contains javac compiler.
  • JRE (Java Runtime Environment): Software bundle required to run compiled Java bytecode. Contains runtime libraries + JVM.
  • JVM (Java Virtual Machine): Abstract software machine that executes bytecode by translating it into CPU-specific machine instructions.
  • History: Developed in 1991 as Oak for interactive television; renamed to Java in 1995; acquired by Oracle Corporation in 2010.

Inside the JDK — the four tools you actually use:

  • javac (Java compiler): translates .java source code into .class bytecode.
  • java (the launcher, part of the JRE): loads a .class file into the JVM and runs it.
  • jdb (Java debugger): steps through a running program to help find bugs.
  • jar (Java Archive tool): packs compiled classes into one .jar file for distribution over a network.
Common mistake: thinking jdb is what executes a program. Compiling uses javac; running uses java; jdb is only for debugging.

Java as an object-oriented language:

  • Low-level language: closest to hardware; Assembly language programs using mnemonics.
  • Middle-level language: e.g. C — procedure/structure-oriented, top-down approach, a collection of functions.
  • High-level language: e.g. Java — object-oriented, bottom-up approach, a collection of objects.

Primary Java Features:

Mnemonic S-P-O-R-T-S-M-D: Simple, Platform-independent, Object-oriented, Robust, Threaded (multithreaded), Secure, Multithreaded, Distributed.

All 12 Java buzzwords (features), in full — this is also called "Why Java?" in exams:

  • Simple: syntax based on C/C++; removed confusing, rarely-used features such as explicit pointers and operator overloading; no manual memory clean-up is needed (the JVM manages it automatically, see 1.2).
  • Object-Oriented: software is organised as a combination of objects, each holding both data and behaviour.
  • Platform independent: the same bytecode runs on Windows, Linux, macOS — anywhere a JVM exists (see 1.2, WORA).
  • Secured: no explicit pointers, every program runs inside the JVM's sandbox, and Java uses a public-key encryption system for security.
  • Robust: strong memory management, no pointers (avoids memory-corruption bugs), and built-in exception handling with compile-time type checking.
  • Architecture neutral: no implementation-dependent feature sizes — e.g. int is always 4 bytes in Java on every platform (exact int sizes in C vary by compiler/platform; the exam point is that Java's size is fixed everywhere).
  • Portable: the same bytecode file can be carried to any platform; the javac compiler itself is written in ANSI C for a clean portability boundary.
  • Dynamic: more adaptive to an evolving environment than C/C++; carries extensive run-time information to verify and resolve access to objects.
  • Interpreted: bytecode is translated on the fly into native machine instructions and is not stored anywhere — it can be interpreted on any system that provides a JVM.
  • High performance: the JIT (Just-In-Time) compiler translates bytecode directly into native machine code for very high speed.
  • Multithreaded: supports writing programs that do many things at once; each thread is like a separate program executing concurrently, and threads share one common memory area.
  • Distributed: designed for the distributed environment of the internet; Java's Remote Method Invocation (RMI) lets a program call methods on another machine over a network.
Mnemonic remember all 12 in three groups of four — SOPS (Simple, OOP, Platform-independent, Secured) · RAPD (Robust, Architecture-neutral, Portable, Dynamic) · IHMD (Interpreted, High-performance, Multithreaded, Distributed).

What is Java, and where is it used?

Definition: Java is both a programming language and a platform — a platform is any hardware or software environment in which a program runs; Java supplies its own software platform, the JRE.
  • Standalone application: a desktop/window-based app installed on a machine, e.g. a media player or antivirus — built using AWT and Swing.
  • Web application: runs on the server and creates dynamic pages, e.g. irctc.co.in — built using Servlet, JSP.
  • Enterprise application: distributed applications such as banking systems — built using EJB.
  • Mobile application: apps for phones — built using Android or Java ME.

Oracle/Sun's own long-standing marketing claim is that Java runs on roughly 3 billion devices worldwide — a promotional figure worth knowing for the exam, not one this course independently verifies.

History of Java — how it got its name:

  • The Java language project was started in June 1991 by James Gosling, Mike Sheridan and Patrick Naughton — a small team of Sun engineers nicknamed the "Green Team" — to write software for digital devices such as set-top boxes and televisions.
  • James Gosling first called the language "Greentalk", with the file extension .gt.
  • It was then renamed "Oak". Oak is a symbol of strength and the national tree of several countries (the reason given in these notes); a commonly told alternative story is that it was named after an oak tree that stood outside Gosling's office — different sources give different reasons.
  • In 1995 the name changed again because "Oak" was already a trademark of Oak Technologies. The team considered "dynamic", "revolutionary", "silk", "jolt", "DNA" before settling on "Java" — Gosling said Java was one of the top choices along with Silk.
  • Java is also the name of an island in Indonesia famous for its coffee, and "java" is common slang for coffee — which is why the Java logo is a coffee cup.
  • Java was originally developed by James Gosling at Sun Microsystems and released in 1995; Sun Microsystems was later acquired by Oracle Corporation in 2010.
