2.4 Five P's of Data Science

The 5 P's answer: why (Purpose), who (People), how (Process), on what (Platforms) and with what code (Programmability). (kyun, kaun, kaise, kis par, kis se)

Definition: The five P's of data science are Purpose, People, Process, Platforms and Programmability: the interdependent parts that together turn big data into a data product and value.
  • Purpose: the challenge or set of challenges defined by the big data strategy; a scientific hypothesis or a business metric to improve. (sawaal kya hai)
  • People: data scientists, domain experts, engineers, managers; data science is teamwork because it needs varied expertise.
  • Process: the organised steps: acquire, prepare, analyse, report, act (2.5). Also covers how the team works and reviews.
  • Platforms: the computing and storage systems: Hadoop / HDFS, Spark, NoSQL databases, cloud, clusters. (kis machine / system par)
  • Programmability: the ability to program the analysis: languages (Python, R, SQL, Java), MapReduce jobs, scripts and workflow tools that make steps repeatable and scalable.
  • Interdependence: purpose chooses people; process decides which platform; platform decides which programming tools.

Three kinds of elements: the 5 P's mix a business element (Purpose), a human element (People), and technological elements (Platforms + Programmability) — with Process as the repeatable workflow that bridges all three.

Worked example: a retail company predicting customer churn
Purpose: identify and predict which customers are most likely to churn (stop buying) in the next three months.
People: data scientists (analysis + models), a domain expert from marketing (business context), data engineers (pipelines), and a business stakeholder (defines the problem, uses the result).
Process: acquire customer data → clean it → EDA to find correlations → build a churn-prediction model → deploy it to a dashboard for the marketing team.
Platforms: a cloud platform (e.g. AWS / Azure / GCP) to store data, plus a big-data framework (e.g. Spark / Hadoop) to process it at scale.
Programmability: Python with a machine-learning library (e.g. scikit-learn) scripts, automates and makes the churn model reproducible.
Mnemonic "Pooja's People Prefer Paneer Pakoda" = Purpose, People, Process, Platforms, Programmability (same order as the wheel, clockwise from top).
Common mistake: writing "Product" or "Price" (marketing 4P) in place of Programmability. Product is the output of the 5 P's, not one of the five.
Quick recall Why-Purpose, Who-People, How-Process, On what-Platforms, With what code-Programmability.
