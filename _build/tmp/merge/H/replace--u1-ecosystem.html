1.12 Hadoop ecosystem and open source technologies

Around the Hadoop core grew a family of open-source tools, each solving one job: ingest, query, store, coordinate, schedule.

Definition: The Hadoop ecosystem is the set of open source projects (mostly under the Apache Software Foundation) that work with HDFS and YARN to ingest, store, process, query, coordinate and manage big data. Open source means the source code is freely available to use, study, modify and redistribute under a licence such as Apache License 2.0.
ToolCategoryOne-line role
HiveQuery / warehouseData warehouse layer that lets you query HDFS data with SQL-like HiveQL (originally developed at Facebook).
PigScriptingHigh-level data-flow language Pig Latin for ETL-style transformations, compiled to jobs (originally developed at Yahoo).
HBaseNoSQL storageDistributed column-family database on HDFS for real-time random read/write, modelled on Google Bigtable.
SqoopIngestionBulk import/export of data between relational databases and Hadoop (the project was retired to the Apache Attic in 2021).
FlumeIngestionCollects, aggregates and moves large volumes of streaming log/event data into HDFS.
ZooKeeperCoordinationCentralised service for configuration, naming, synchronisation and leader election in distributed systems — in the project's own words, for "maintaining configuration information, naming, providing distributed synchronization, and providing group services".
OozieWorkflowWorkflow scheduler that runs chains of Hadoop jobs (Hive, Pig, MapReduce) in order or on a time/data trigger.
SparkProcessingFast general-purpose engine using in-memory computation for batch, SQL, streaming and machine learning (originated at UC Berkeley).
KafkaStreamingDistributed publish–subscribe event-streaming platform for high-throughput real-time data pipelines (originated at LinkedIn).
PrestoQuery (SQL engine)Distributed SQL query engine for running interactive analytic queries directly over HDFS and other sources, from gigabytes to petabytes; originated at Facebook (2012), open-sourced in 2013.
ImpalaQuery (SQL engine)Massively parallel, low-latency SQL query engine for data in HDFS/HBase, originated at Cloudera and now an Apache Software Foundation project.
ZeppelinAnalytics notebookApache web-based notebook (like Jupyter) for interactive, visual data analytics on top of Spark and Hadoop.
  • Open source advantages: no licence fee, large community, transparency, no vendor lock-in, rapid innovation.
  • Open source challenges: support depends on community or paid vendors, integration and version compatibility effort, need for skilled staff.
  • Commercial distributions bundled and supported these tools (e.g. Cloudera; Hortonworks merged with Cloudera in 2019).

Mnemonic Group by job: Ingest = Sqoop, Flume, Kafka · Store = HDFS, HBase · Process = MapReduce, Spark · Query = Hive, Pig, Presto, Impala · Manage = ZooKeeper (zoo-keeper looks after the animals), Oozie (schedules the jobs) · Notebook = Zeppelin.
Common mistake: class-note slides list Presto as "Developed by: Apache Software Foundation". Presto actually originated at Facebook (development started 2012, open-sourced in 2013) and since 2019 is governed by the Presto Foundation under the Linux Foundation, not the Apache Software Foundation — unlike Hive, Pig, HBase, Impala, Oozie and ZooKeeper, which genuinely are Apache Software Foundation projects. Also: Sqoop moves bulk data from RDBMS; Flume moves streaming log data — do not swap them.
Quick recall Hive = SQL, Pig = scripts, HBase = NoSQL on HDFS, Sqoop = RDBMS transfer, Flume = logs, ZooKeeper = coordination, Oozie = workflows, Spark = in-memory engine, Kafka = event streaming, Presto/Impala = interactive SQL engines, Zeppelin = analytics notebook.
