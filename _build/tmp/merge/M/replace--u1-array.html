1.9 Arrays (1D, 2D, and Jagged Arrays)

An array organizes multiple data items of the same type under a single variable name indexed sequentially. (ek naam ke andar multiple elements rakhna)

Definition: An array is a fixed-size, contiguous indexed collection of homogeneous elements stored in contiguous heap memory.
  • 1D Array: Single row of elements accessed by index arr[i] (0 to length-1).
  • 2D Array: Array of 1D arrays forming a matrix/table of rows and columns accessed as arr[r][c].
  • Jagged Array: Multi-dimensional array in which sub-arrays have different lengths.
  • Declaration only creates a reference, no memory for elements yet: int marks[]; (or int[] marks;).
  • Creation uses new to allocate memory on the heap for the given size: marks = new int[6];. Every element is auto-initialised to the type's default value (0 for int, false for boolean, null for object types) until assigned.
  • Declaration + creation together: int marks[] = new int[6];
  • Declaration + initialization (size is inferred from the value list, new int[] is implicit): int marks[] = {60, 58, 70, 80, 78, 89};
  • 2D array creation: int marks[][] = new int[3][6]; allocates 3 rows of 6 columns each; or with an initializer int marks[][] = {{...}, {...}, {...}};.
AdvantageWhy
Code optimizationOne variable holds many values; data is easy to retrieve and sort.
Random accessAny element can be read directly by its index, in O(1) time.

Disadvantage - Size limit: an array is fixed-size and cannot grow at runtime; when the size must change, the Collection framework (e.g. ArrayList) is used instead.

Program 1: 1D Array traversing, calculating sum and finding maximum element.

public class Array1DDemo {
    public static void main(String[] args) {
        int[] arr = {12, 45, 7, 23, 89, 34};
        int sum = 0;
        int max = arr[0];
        for (int val : arr) {
            sum += val;
            if (val > max) max = val;
        }
        System.out.println("Sum = " + sum + ", Max = " + max);
    }
}
Sum = 210, Max = 89

Program 2: 2D Matrix Addition.

public class Array2DDemo {
    public static void main(String[] args) {
        int[][] a = {{1, 2}, {3, 4}};
        int[][] b = {{5, 6}, {7, 8}};
        int[][] sum = new int[2][2];
        for (int i = 0; i < 2; i++) {
            for (int j = 0; j < 2; j++) {
                sum[i][j] = a[i][j] + b[i][j];
                System.out.print(sum[i][j] + " ");
            }
            System.out.println();
        }
    }
}

Program 3: declaring, creating and initializing a 1D array element-by-element, then traversing it with .length.

public class SingleDarray {
    public static void main(String[] args) {
        int marks[] = new int[6]; // Declaration
        marks[0] = 60; // Initialization
        marks[1] = 58;
        marks[2] = 70;
        marks[3] = 80;
        marks[4] = 78;
        marks[5] = 89;
        // printing values in array
        for (int i = 0; i < marks.length; i++) {
            System.out.println(marks[i]);
        }
    }
}

Program 4: declaring, creating and initializing a 2D array (3 rows, 6 columns) element-by-element, then traversing it with a nested loop.

public class TwoDarray {
    public static void main(String[] args) {
        int marks[][] = new int[3][6];
        marks[0][0] = 48; marks[0][1] = 52; marks[0][2] = 63;
        marks[0][3] = 65; marks[0][4] = 66; marks[0][5] = 71;
        marks[1][0] = 67; marks[1][1] = 78; marks[1][2] = 87;
        marks[1][3] = 65; marks[1][4] = 64; marks[1][5] = 76;
        marks[2][0] = 78; marks[2][1] = 67; marks[2][2] = 65;
        marks[2][3] = 77; marks[2][4] = 75; marks[2][5] = 82;
        // printing 2-D array
        for (int i = 0; i < marks.length; i++) {
            for (int j = 0; j < marks[i].length; j++) {
                System.out.print(marks[i][j] + " ");
            }
            System.out.println();
        }
    }
}

Common mistake: Array indices in Java start at 0 and end at length - 1. Accessing arr[arr.length] throws ArrayIndexOutOfBoundsException.
Common mistake: Declaring an array (int marks[];) does not create it. Using an element before new int[size] has run throws NullPointerException because the reference still points to nothing.
Quick recall Arrays in Java are zero-indexed objects stored on the heap; arr.length gives total size. Declaration makes a reference, new allocates the memory. Jagged arrays have sub-arrays of different row lengths.
