1.1 Machine Learning: basic concepts

Instead of writing rules by hand, we show the computer examples and it finds the rules itself. (rules hum nahi likhte, data se machine khud seekhti hai)

Definition (Tom Mitchell, 1997): "A computer program is said to learn from experience E with respect to some class of tasks T and performance measure P, if its performance at tasks in T, as measured by P, improves with experience E."
Informal definition (commonly attributed to Arthur Samuel, 1959): Machine learning is the field of study that gives computers the ability to learn without being explicitly programmed.
  • Learning = improving at a task (T), measured by P, through experience E. (practice se better hona)
  • Task T: what the system must do, e.g. classify an email as spam or not.
  • Performance P: a number that tells how well it does, e.g. accuracy (% correct).
  • Experience E: the data or practice it learns from, e.g. emails already labelled spam / not spam.
  • Well-posed learning problem: a problem where T, P and E are all clearly identified (Mitchell).
  • ML is used when rules are too hard to write by hand (face recognition), when rules change (spam tricks change), or when data is huge.

1.2 Basic terminology

Before any algorithm, learn the vocabulary: rows, columns, answers, and how well the model does on new data. (ML ki basic bhasha)

Definition: A dataset is a collection of examples (instances); each example is described by features (input attributes) and, in supervised learning, a label (target output). A model is the function learned from the training set that maps features to outputs.
  • Instance / example / sample: one row of the dataset (one house, one email).
  • Feature (attribute): one input column, e.g. area, rooms. (input column)
  • Label (target): the answer column we want to predict, e.g. price, spam / not spam.
  • Training set: data the model learns from. Test set: data kept aside to check the model on unseen cases. A validation set is sometimes also kept for tuning.
  • Model: the learned mapping f(x) → y. Hypothesis h: one candidate function the learner considers; the hypothesis space H is the set of all candidates.
  • Target function: the true (unknown) function we want to learn; the model is an approximation of it.
  • Generalization: ability to perform well on new, unseen data, not just training data. (naye data pe bhi sahi)
  • Overfitting: model memorises training data including noise; training error low, test error high.
  • Underfitting: model too simple to capture the pattern; both training and test error high.
  • Bias: error from wrong / too-simple assumptions (causes underfitting). Variance: error from being too sensitive to the particular training set (causes overfitting).
  • Bias-variance trade-off: making the model more complex lowers bias but raises variance; the best model balances both. For squared error, expected error = bias² + variance + irreducible noise.

1.3 ML workflow (life cycle)

Building an ML system is a step-by-step pipeline, from defining the problem to watching the model after launch. (problem se deploy tak ka safar)

Definition: The machine learning life cycle is the ordered set of steps used to build and maintain an ML model: define the problem, collect and prepare data, choose and train a model, evaluate it, and deploy and monitor it.
  • Define problem: fix T, P, E; decide classification, regression, clustering, etc.
  • Collect data: databases, sensors, logs, web, surveys.
  • Prepare data: remove duplicates, handle missing values and outliers. (safai)
  • Feature engineering: pick useful features, encode categories, scale numbers (see 1.10).
  • Choose and train model: fit the algorithm on the training set.
  • Evaluate: test set metrics - accuracy, precision, recall (classification); MSE, RMSE (regression).
  • Tune: adjust hyperparameters using a validation set, then re-evaluate.
  • Deploy and monitor: put into an app; watch for performance drop when real data changes, retrain when needed.
Example
Food-delivery time prediction: problem = predict minutes (regression).
Data = past orders: distance, restaurant prep time, hour, weather. Label = actual delivery minutes.
Train → test error checked → deploy in app → monitor during festivals and rain, retrain.
Problem → Data → Prepare → Features → Model → Train → Evaluate → Deploy
Mnemonic "Please Cook Paneer For My Tiffin Every Day" = Problem, Collect, Prepare, Features, Model, Train, Evaluate, Deploy.
Quick recall 8 steps, and it is a loop: poor evaluation sends you back to data or model.

1.4 Designing a learning system (Mitchell)

Mitchell designs a checkers-playing learner by making four choices one after another. (chaar faisle = ek learning system)

Definition: Designing a learning system means making four design choices: (1) the training experience, (2) the exact target function to learn, (3) a representation for that function, and (4) a learning algorithm (function approximation algorithm) to learn it from training examples.

Step 1: Choose the training experience

  • Direct vs indirect feedback: direct = board states each labelled with the correct move; indirect = only the final win / loss of whole games, so credit must be assigned to earlier moves (credit assignment problem).
  • Control over sequence: teacher picks examples, or learner asks the teacher, or learner explores on its own (plays against itself).
  • Representative distribution: training examples should look like the cases the final system will be tested on. Learning only from self-play may miss positions a human champion would play.

Step 2: Choose the target function

  • Direct choice: ChooseMove : B → M (board state to best legal move) - hard to learn with indirect experience.
  • Mitchell's choice: V : B → ℝ, an evaluation function giving a higher score to better board states. Pick the move leading to the highest V.
  • Ideal V: +100 for a won board, -100 for a lost board, 0 for a draw; for other boards V(b) = V(b′) of the best final board reachable. This is not efficiently computable, so we learn an approximation V̂.

Step 3: Choose a representation

  • Linear function of six board features: V̂(b) = w0 + w1x1 + w2x2 + w3x3 + w4x4 + w5x5 + w6x6
  • x1 = black pieces, x2 = red pieces, x3 = black kings, x4 = red kings, x5 = black pieces threatened by red, x6 = red pieces threatened by black.
  • Learning now means finding good weights w0 to w6. A richer representation can express more, but needs more data. (zyada powerful = zyada data chahiye)

Step 4: Choose a learning algorithm

  • Estimate training values: V_train(b) ← V̂(Successor(b)), where Successor(b) is the next board after the program's move and the opponent's reply.
  • Adjust weights with LMS (least mean squares) to reduce squared error E = Σ (V_train(b) − V̂(b))²:
  • For each training example: wi ← wi + η (V_train(b) − V̂(b)) xi, where η is a small learning rate (e.g. 0.1).

1.5 Perspectives in Machine Learning

Different ways of looking at the same thing: learning is searching, estimating probabilities, or minimising error. (ek hi cheez ko alag nazariye se dekhna)

Definition (Mitchell): One useful perspective on machine learning is that it involves searching a very large space of possible hypotheses to determine one that best fits the observed data and any prior knowledge held by the learner.
  • Learning as search: in checkers, H = all functions V̂ that weights w0..w6 can express; LMS searches H by tuning weights. (sahi hypothesis dhoondhna)
  • Different algorithms = different ways of searching different hypothesis spaces: numeric weights (linear models, neural nets), decision trees, rules.
  • Viewing learning as search lets us analyse size of H, number of examples needed, and confidence in the result.
  • Statistical / probabilistic perspective (Murphy): data comes from an unknown probability distribution; learning = estimating it and predicting with uncertainty, e.g. P(spam | words).
  • Optimization perspective: choose a loss function (e.g. squared error) and find parameters that minimise it (gradient descent, LMS).
  • Function approximation: learn an approximation f̂ of an unknown target function f from input-output examples.
  • Multi-disciplinary roots (Mitchell ch. 1): artificial intelligence, Bayesian methods, computational complexity theory, control theory, information theory, philosophy, psychology and neurobiology, statistics.
DisciplineWhat it gives to ML
StatisticsEstimating from samples, confidence, hypothesis testing
Bayesian methodsProbability as degree of belief; naive Bayes classifier

Common mistake: Thinking the search is random guessing. The search is guided: each new hypothesis is chosen to reduce error on the training data.
Quick recall Mitchell: learning = search in hypothesis space H for h that best fits data + prior knowledge. Also: statistical, optimization, function approximation views.

1.6 Issues in Machine Learning

The open questions and real-world headaches that decide whether an ML system works. (ML ki mushkilein)

Definition: Issues in machine learning are the fundamental questions (which algorithm, how much data, what prior knowledge, which experience, what function, what representation) and practical problems (data quality, overfitting, bias, interpretability, computation) that affect how well a learner generalizes.

Mitchell's issues (textbook list)

  • Algorithms: What algorithms exist for learning general target functions from specific training examples? In what settings do they converge to the desired function given enough data? Which work best for which problems and representations?
  • Amount of training data: How much training data is sufficient? What bounds relate confidence in the learned hypothesis to the amount of experience and the character of the hypothesis space?
  • Prior knowledge: When and how can the learner's prior knowledge guide generalization? Can it help even when only approximately correct?
  • Choosing training experience: What is the best strategy for choosing the next training experience, and how does this choice change the complexity of the learning problem?
  • Reducing to function approximation: What is the best way to reduce the learning task to one or more function approximation problems? Which specific functions should be learned? Can this itself be automated?
  • Altering representation: How can the learner automatically change its representation to improve its ability to represent and learn the target function?

Practical issues

  • Data quality: missing values, noise, wrong labels, outliers. (garbage in, garbage out)
  • Insufficient or unrepresentative data: model fails on cases it never saw.
  • Overfitting / underfitting: poor generalization (see Fig 1.4).
  • Bias and fairness: if training data is skewed (e.g. mostly one group), predictions can be unfair to others.
  • Interpretability: complex models (deep nets) are hard to explain - a problem in loans and medicine.
  • Computation cost: large data and models need time, memory, GPUs.
  • Privacy and security: personal data must be protected; models can be fooled by crafted inputs.
  • Concept drift: real-world data changes over time, so accuracy drops unless retrained.

1.7 Types of Machine Learning: supervised learning

Types are decided by what feedback the learner gets: correct answers, no answers, or rewards. (teacher hai, teacher nahi, ya inaam-saza)

Definition: Supervised learning learns a mapping from inputs X to outputs Y using a labelled training set of pairs (x, y), so that it can predict y for new x. If y is a category it is classification; if y is a continuous number it is regression.
  • Needs a teacher / supervisor: every training example has the correct answer. (answer key ke saath padhai)
  • Classification: output is a discrete class. Binary (spam / not spam) or multi-class (digit 0-9).
  • Regression: output is a real number (house price, temperature, delivery time).
  • Algorithms: KNN, decision tree, naive Bayes, logistic regression, SVM (classification); linear regression (regression). Covered in Unit II.
  • Evaluation: accuracy, precision, recall (classification); MSE, RMSE, MAE (regression).
  • Limitation: labelling data is costly and slow.

1.8 Unsupervised learning

No answers are given; the algorithm finds groups and hidden structure on its own. (bina teacher ke pattern dhoondhna)

Definition: Unsupervised learning finds patterns, groups or structure in unlabelled data (only x, no y). Main tasks are clustering, dimensionality reduction and association rule mining.
  • Clustering: put similar items in the same group. E.g. customer segmentation by spending habits. (milte-julte ek group mein)
  • Dimensionality reduction: reduce many features to fewer while keeping most information (PCA); helps visualisation and speed.
  • Association rules: find items that occur together - market basket analysis, e.g. rule {bread} → {butter}.
  • Anomaly detection is often done unsupervised: flag points unlike the rest (unusual transactions).
  • Advantage: no labelling cost. Limitation: results are harder to evaluate because there is no answer key.

1.9 Reinforcement learning, semi-supervised learning and comparison

Learn by trial and error: try an action, get a reward or penalty, repeat to maximise total reward. (inaam aur saza se seekhna)

Definition: Reinforcement learning is learning in which an agent interacts with an environment, takes actions in states, receives rewards, and learns a policy (state → action) that maximises cumulative reward over time.
  • Agent: the learner / decision maker (robot, game player).
  • Environment: everything the agent interacts with (game board, road).
  • State s: current situation. Action a: what the agent does.
  • Reward r: number fed back; positive = good, negative = penalty. Often delayed (win known only at the end).
  • Policy π: the rule mapping states to actions; goal is the policy with maximum total reward.
  • Exploration vs exploitation: try new actions to learn, or use the best known action to earn reward. (naya try karein ya jo pata hai wahi karein)
  • Algorithms: Q-learning, SARSA, deep Q-networks. Examples: game playing (DeepMind's AlphaGo used RL along with supervised learning and tree search), robot walking, Mitchell's checkers player learning from self-play.

Semi-supervised learning (brief)

  • Semi-supervised learning uses a small labelled set plus a large unlabelled set; useful when labelling is expensive.
  • Example: a few hundred labelled medical scans with thousands unlabelled; the model labels confident unlabelled cases and retrains (self-training).

1.10 Data representation: numerical representation

Algorithms only understand numbers, so every email, image or colour must first become a list of numbers. (sab kuch number mein badlo)

Definition: Numerical representation expresses each example as a feature vector x = (x1, x2, ..., xd) ∈ ℝᵈ of d numeric features. A dataset of n examples is stored as an n × d feature matrix X, with labels in an n × 1 vector y.
  • Feature vector: one row. House → x = (1200, 3, 5) for (area, rooms, age).
  • Feature matrix: rows = examples (n), columns = features (d). The 3-house table in 1.2 gives X of size 3 × 3. (rows = examples, columns = features)
  • Numerical features: continuous (area, price) or discrete counts (rooms).
  • Categorical features: text values (colour, city) must be encoded.
  • Label encoding: each category → an integer. Good for ordered categories (low < medium < high); for unordered ones it wrongly implies an order.
  • One-hot encoding: one 0/1 column per category, exactly one 1 per row. No false order, but more columns.
  • Feature scaling: bring features to similar ranges so a large-range feature (salary) does not dominate a small one (age). Needed for distance-based methods like KNN.
  • Min-max normalization: x′ = (x − min) / (max − min), result in [0, 1].
  • Z-score standardization: z = (x − μ) / σ, result has mean 0 and standard deviation 1.
  • Images: a grayscale image is a matrix of pixel intensities 0-255; a 28 × 28 image flattens to 784 features. Colour images have 3 channels (R, G, B): H × W × 3.
  • Text (bag-of-words): build a vocabulary; each document = vector of word counts. Word order is ignored.

1.11 Data representation: graph representation

When the relationships between items matter (who is friends with whom), store the data as a graph of nodes and edges. (rishton wala data = graph)

Definition: A graph G = (V, E) consists of a set of vertices (nodes) V representing entities and a set of edges E representing relationships between pairs of nodes. Edges may be directed or undirected, and weighted or unweighted. It is stored as an adjacency matrix or an adjacency list.
  • Node: an entity (person, product, web page, atom). Edge: a relation (friend, bought, link, bond).
  • Undirected: relation both ways (Facebook-style friendship). Directed: one way (following someone on Instagram, a web link). (ek taraf ya dono taraf)
  • Weighted: edge carries a number (distance, rating, strength).
  • Degree: number of edges at a node; directed graphs have in-degree and out-degree.
  • Adjacency matrix: V × V table, A[i][j] = weight (or 1) if edge i-j exists, else 0. Symmetric for undirected graphs. Space O(V²); edge check O(1).
  • Adjacency list: for each node, a list of its neighbours. Space O(V + E); best for sparse graphs.
  • Node features can be kept as vectors too, so graph ML combines numerical + graph representation. Graph Neural Networks (GNNs) learn directly on graphs.

Where graphs are used in ML

  • Social networks: users = nodes, friendships = edges; friend suggestion is link prediction.
  • Recommendation systems: user-item bipartite graph (user bought / rated item); recommend items linked to similar users.
  • Knowledge graphs: entities and facts as triples, e.g. (Delhi, capital of, India); used by search engines to answer questions (Google introduced its Knowledge Graph in 2012).
  • Chemistry / biology: molecules with atoms as nodes and bonds as edges; predict molecule properties.
  • Road networks: junctions and roads; travel-time estimation and route planning.
  • Fraud detection: accounts and transactions forming suspicious rings.

1.13 Short answers (1.5 marks)

Define machine learning (Mitchell).
A program learns from experience E with respect to tasks T and performance measure P if its performance at T, measured by P, improves with E.
What is a well-posed learning problem? Give T, P, E for checkers.
A learning problem with clearly identified task, performance measure and experience. Checkers: T = playing checkers, P = % games won, E = games played against itself.
Differentiate traditional programming and ML.
Traditional: data + hand-written rules → output. ML: data + example outputs → learned rules (model), which then predict outputs for new data.
How are AI, ML and DL related?
DL ⊂ ML ⊂ AI. AI = intelligent behaviour by machines; ML = AI that learns from data; DL = ML using multi-layer neural networks.
What is overfitting?
The model fits training data including noise, giving very low training error but high test error, i.e. poor generalization. Caused by high variance.
Define generalization.
The ability of a learned model to perform well on new, unseen data drawn from the same distribution as the training data.
What is a hypothesis space?
The set H of all candidate functions a learner can choose from; learning is a search through H for the hypothesis that best fits the data.
List the four choices in designing a learning system.
(1) Training experience, (2) target function, (3) representation of target function, (4) function approximation (learning) algorithm.
Name the four modules of Mitchell's final design.
Performance System, Critic, Generalizer, Experiment Generator.
Write the LMS weight update rule.
wi ← wi + η (V_train(b) − V̂(b)) xi, where η is a small learning rate and xi is the i-th board feature.
List any four issues in machine learning.
Choice of algorithm, amount of training data, use of prior knowledge, choice of representation (also: data quality, overfitting, bias, interpretability).
Differentiate classification and regression.
Both are supervised. Classification predicts a discrete class (spam / not spam); regression predicts a continuous value (house price).
What is unsupervised learning? Give two tasks.
Learning patterns from unlabelled data. Tasks: clustering (K-means) and dimensionality reduction (PCA); also association rules.
Define agent, state, action and reward in RL.
Agent = learner that acts; state = current situation; action = choice made by the agent; reward = numeric feedback from the environment for that action.
What is semi-supervised learning?
Learning from a small labelled set together with a large unlabelled set, used when labelling data is expensive.
What is a feature vector and a feature matrix?
Feature vector = the d numeric features of one example, x ∈ ℝᵈ. Feature matrix = n examples stacked as rows, size n × d.
Differentiate label encoding and one-hot encoding.
Label encoding gives each category one integer (Blue 0, Green 1, Red 2). One-hot gives one 0/1 column per category (Red = [0, 0, 1]), avoiding false order.
Differentiate adjacency matrix and adjacency list.
Matrix: V × V array, O(V²) space, O(1) edge check, good for dense graphs. List: neighbours per node, O(V + E) space, good for sparse graphs.
