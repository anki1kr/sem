2.1 Basic Concepts of Linear Prediction & Normal Equations

Linear prediction estimates the current speech sample as a weighted linear combination of past speech samples. (purane samples se naya sample predict karo)

Definition: Linear prediction (LP) models the current speech sample s[n] as a linear combination of p previous samples: ŝ[n] = ∑_i=1^p a_i s[n-i]. The prediction error is e[n] = s[n] - ŝ[n] = s[n] - ∑_i=1^p a_i s[n-i].
  • Why Speech is Predictable: Vocal tract inertia creates strong correlation between adjacent samples, and glottal quasi-periodicity creates inter-pitch correlation.
  • Derivation of Normal Equations: Minimizing the Mean Squared Prediction Error E = ∑e^2[n] = ∑( s[n] - ∑_i=1^p a_i s[n-i] )^2 with respect to predictor coefficients a_k ((∂E)/(∂a_k) = 0) yields the Yule-Walker / Autocorrelation Normal Equations: ∑_i=1^p a_i R[|k-i|] = R[k] for k = 1, 2, …, p
  • Matrix Form (p=2): [ R[0] R[1]; R[1] R[0] ] [ a_1; a_2 ] = [ R[1]; R[2] ]
Worked Example: Order-2 Linear Prediction Normal Equations Solving
Given autocorrelation values: R[0] = 5.0, R[1] = 3.0, R[2] = 1.0.
Set up matrix equation: [ 5.0 3.0; 3.0 5.0 ] [ a_1; a_2 ] = [ 3.0; 1.0 ]
Determinant Δ = (5.0)(5.0) - (3.0)(3.0) = 25 - 9 = 16.0.
a_1 = (3.0(5.0) - 1.0(3.0))/(16.0) = (15 - 3)/(16) = (12)/(16) = 0.75
a_2 = (5.0(1.0) - 3.0(3.0))/(16.0) = (5 - 9)/(16) = (-4)/(16) = -0.25
Minimum residual error energy E_2 = R[0] - a_1 R[1] - a_2 R[2] = 5.0 - (0.75)(3.0) - (-0.25)(1.0) = 5.0 - 2.25 + 0.25 = 3.0.
Predictor Coefficients: a1 = 0.75, a2 = -0.25; Residual Energy E2 = 3.0
Quick recall LP predicts current sample s[n] from p past samples; normal equations ∑a_i R[|k-i|] = R[k] minimize mean squared error.

2.2 LP Analysis of Non-Stationary Signals & Prediction Gain

Speech is a non-stationary signal, so LP analysis is performed on short quasi-stationary frames of 20 to 30 milliseconds. (20-30 ms ke chhote frames me analysis hota hai)

Definition: Linear prediction analysis treats non-stationary speech as quasi-stationary by segmenting it into short overlapping frames (20 ms - 30 ms) multiplied by a smooth window function (such as a Hamming window).
  • Autocorrelation Method vs Covariance Method:
    • Autocorrelation Method: Windows the speech frame so it vanishes outside bounds. Guarantees a stable filter (|k_i| < 1).
    • Covariance Method: Does not window signal outside frame; requires no zero-padding, but filter stability is not guaranteed.
  • Prediction Gain (PG): Quantitative measure of LP compression efficiency defined as the ratio of speech variance to prediction error variance: PG = 10 log_10 ( (σ_s^2)/(σ_e^2) ) = 10 log_10 ( (R[0])/(E_p) ) dB
Worked Example: Prediction Gain Calculation
From previous order-2 example: Signal variance R[0] = 5.0, Prediction error energy E_2 = 3.0.
PG = 10 log_10 ( (5.0)/(3.0) ) = 10 log_10(1.6667) = 10 × (0.22185) = 2.2185 dB.
Prediction Gain PG = 2.218 dB
Quick recall Speech is non-stationary → analyze in 20-30 ms frames with Hamming windows. Prediction gain PG = 10 log_10(σ_s^2/σ_e^2) dB.

2.3 Levinson-Durbin Algorithm & Reflection Coefficients

The Levinson-Durbin algorithm solves normal equations recursively in O(p²) time while generating reflection coefficients. (O(p^2) me fast solve aur stability test)

Definition: The Levinson-Durbin algorithm is an efficient recursive algorithm that solves the Yule-Walker matrix equations in O(p^2) operations, computing predictor coefficients a_i alongside intermediate reflection coefficients k_i.
  • Reflection Coefficients (k_i): Intermediate parameters generated during Levinson-Durbin recursion.
  • Stability Condition: An all-pole filter is strictly stable if and only if all reflection coefficients satisfy |k_i| < 1 for i = 1 …p.
  • Computational Complexity: Reduces matrix inversion complexity from O(p^3) to O(p^2).
Worked Example: Levinson-Durbin Recursion Step-by-Step
Given R[0] = 5.0, R[1] = 3.0, R[2] = 1.0. Solve for order p=2.
Initialization: E_0 = R[0] = 5.0.
Iteration 1 (i=1):
k_1 = (R[1])/(E_0) = (3.0)/(5.0) = 0.6 (Since |0.6| < 1, stable)
a_1^(1) = k_1 = 0.6
E_1 = (1 - k_1^2) E_0 = (1 - 0.36) × 5.0 = 0.64 × 5.0 = 3.2
Iteration 2 (i=2):
k_2 = (R[2] - a_1^(1) R[1])/(E_1) = (1.0 - (0.6)(3.0))/(3.2) = (1.0 - 1.8)/(3.2) = (-0.8)/(3.2) = -0.25 (Since |-0.25| < 1, stable)
a_2^(2) = k_2 = -0.25
a_1^(2) = a_1^(1) - k_2 a_1^(1) = 0.6 - (-0.25)(0.6) = 0.6 + 0.15 = 0.75
E_2 = (1 - k_2^2) E_1 = (1 - (-0.25)^2) × 3.2 = (1 - 0.0625) × 3.2 = 0.9375 × 3.2 = 3.0
Reflection coeffs: k1 = 0.6, k2 = -0.25; Predictor coeffs: a1 = 0.75, a2 = -0.25 (Matches direct matrix solve)
Quick recall Levinson-Durbin solves normal equations in O(p^2) time; filter is stable if all reflection coefficients |k_i| < 1.

2.4 Short-Term vs Long-Term LP Models & Moving Average Prediction

Short-term prediction removes vocal tract spectral envelope correlation, while long-term prediction removes pitch periodicity correlation. (short-term formant nikalta hai, long-term pitch)

Definition: A complete speech prediction system uses a cascade of a short-term predictor (order p ≈10 modeling vocal tract formants) and a long-term predictor (pitch predictor modeling pitch period T).

Short-Term LPVocal tract spectral envelope (formants)Order p ≈10 – 12Short-lag adjacent sample correlation
Long-Term LPVocal cord vibration periodicity (pitch)Pitch lag T + gain b (1 – 3 taps)Long-lag pitch period correlation
Moving Average (MA)Predicts from past prediction errors e[n-k]FIR all-zero predictor B(z)Noise-like error correlations
Quick recall Short-term LP (p ≈10) models vocal tract envelope; Long-term LP models pitch period T; MA models error sequence.

2.5 Scalar Quantization (Uniform, Optimum Lloyd-Max, Logarithmic Companding)

Quantization maps continuous amplitude values into discrete levels, introducing irreversible quantization noise. (continuous amplitude ko fixed levels me convert karna)

Definition: Scalar quantization maps a continuous amplitude scalar sample x to a discrete reconstruction level y_k = Q(x) selected from a set of decision boundaries x_k.
  • Uniform Quantizer: Equal step size Δ = (x_max - x_min)/(L).
    • Mid-tread: Origin 0 is a reconstruction level.
    • Mid-rise: Origin 0 is a decision boundary.
    • SQNR Formula (for N-bit quantizer with full-scale sinusoid): SQNR ≈6.02 N + 1.76 dB Rule of thumb: Each additional bit adds ≈6 dB of SQNR.
  • Optimum Lloyd-Max Quantizer: Non-uniform quantizer that minimizes Mean Squared Error (MSE) for a known PDF:
    • Boundary Condition: Decision boundary x_k = (y_k + y_k+1)/(2) (midpoint of adjacent levels).
    • Reconstruction Condition: y_k = (∫_x_k-1^x_k x p(x) dx)/(∫_x_k-1^x_k p(x) dx) (centroid of PDF interval).
  • Logarithmic Quantizer (Companding): Compresses dynamic range before uniform quantization and expands at receiver:
    • μ-law (North America/Japan): y = sgn(x) (ln(1 + μ|x|))/(ln(1 + μ)) with μ= 255.
    • A-law (Europe/International): Uses A = 87.6.
Worked Example: Uniform Quantizer SQNR and Companding Calculation
1. 3-Bit Uniform Quantizer: N = 3 bits (L = 2^3 = 8 levels).
SQNR ≈6.02(3) + 1.76 = 18.06 + 1.76 = 19.82 dB.
2. Logarithmic μ-law compression for x = 0.5 (μ= 255):
y = (ln(1 + 255 × 0.5))/(ln(1 + 255)) = (ln(128.5))/(ln(256)) = (4.8559)/(5.5452) = 0.8757.
SQNR (3-bit) = 19.82 dB; Compressed mu-law value y = 0.8757
Quick recall Uniform SQNR ≈6.02 N + 1.76 dB; Lloyd-Max places boundaries midway and levels at centroids; μ-law (μ=255) compresses weak signals.

2.6 Adaptive and Differential Quantizers (AQF, AQB, DPCM, ADPCM)

Adaptive quantizers adjust step sizes dynamically, while differential quantizers quantize the difference between actual and predicted samples. (step size change karo aur difference ko quantize karo)

Definition: Adaptive quantization adapts quantizer step size Δ[n] to local signal variance, while differential quantization (DPCM) quantizes difference samples d[n] = s[n] - ŝ[n] to exploit sample correlation.
  • Adaptive Quantization:
    • Forward AQF: Step size calculated from input speech frame; transmitted as side information.
    • Backward AQB: Step size estimated from past quantized output; no side information needed.
  • Differential PCM (DPCM): Encoder quantizes difference d[n] = s[n] - ŝ[n]. Predictor lives in feedback loop using reconstructed samples s̃[n] so encoder and decoder stay synchronized.
  • ADPCM (Adaptive DPCM): Combines adaptive quantization step size with an adaptive predictor (e.g., ITU G.726 @ 32 kbps).
Quick recall AQF transmits explicit step size; AQB estimates it from past quantized output. DPCM quantizes difference d[n] = s[n] - ŝ[n]; ADPCM adds adaptive prediction.

2.7 Vector Quantization (Distortion Measures, LBG Algorithm, Codebook Types)

Vector quantization groups vectors of samples and matches them to the nearest codeword in a stored codebook. (poore vector ko codebook ke codeword se match karo)

Definition: Vector quantization (VQ) blocks k consecutive samples into a k-dimensional vector 𝐱 and maps it to the closest codevector 𝐲_i in a codebook C = {𝐲_1, …, 𝐲_N}, transmitting only the codebook index i.
  • Distortion Measures:
    • Squared Euclidean Distance (MSE): d(𝐱, 𝐲) = 𝐱 - 𝐲^2 = ∑_j=1^k (x_j - y_j)^2.
    • Weighted Euclidean Distance: d_W(𝐱, 𝐲) = (𝐱 - 𝐲)^T 𝐖 (𝐱 - 𝐲).
    • Itakura-Saito Distance: Measures spectral distortion between LPC spectral envelopes P(ω) and P̂(ω).
  • LBG Algorithm (Linde-Buzo-Gray / Generalized Lloyd Algorithm):
    1. Start with initial codebook (or split overall centroid).
    2. Partitioning: Assign training vectors to nearest codevector using distortion measure (Voronoi region partition).
    3. Update: Recompute each codevector as the centroid of assigned vectors.
    4. Check Convergence: If fractional distortion reduction (D_m-1 - D_m)/(D_m) < ϵ, stop; else repeat.
Codebook ArchitectureSearch ComplexityMemory RequirementPrimary Advantage
Full-Search (Unstructured)O(N) (High)O(N ·k)Lowest distortion, optimal codebook
Tree-Structured VQ (TSVQ)O(log_2 N) (Very Low)O(2 N ·k)Fast binary tree search
Multistage VQ (MSVQ)O(M ·N^1/M)LowLow complexity for large codebooks
Split VQLow (splits vector)Very LowCommon for LPC parameter quantization
Worked Example: Tiny LBG 2D Codebook Centroid Update
Given 4 2D points: P_1(1,2), P_2(2,4), P_3(7,8), P_4(9,10).
Initial overall centroid: C = ((1+2+7+9)/(4), (2+4+8+10)/(4)) = (4.75, 6.0).
Split into 2 initial codevectors: C_1 = (4, 5) and C_2 = (5, 7).
Partitioning by nearest Euclidean distance:
P_1(1,2) and P_2(2,4) are closer to C_1(4,5) → Region R_1.
P_3(7,8) and P_4(9,10) are closer to C_2(5,7) → Region R_2.
Updated Centroids:
C_1^* = ((1+2)/(2), (2+4)/(2)) = (1.5, 3.0)
C_2^* = ((7+9)/(2), (8+10)/(2)) = (8.0, 9.0)
Updated LBG Centroids: C1* = (1.5, 3.0), C2* = (8.0, 9.0)
Quick recall VQ quantizes sample vectors directly; LBG algorithm designs codebooks via Voronoi partitioning and centroid updating.

2.8 Short answers (1.5 marks)

1. Define Linear Prediction in speech processing.
Estimation technique that predicts current speech sample s[n] as a weighted sum of p past samples: ŝ[n] = ∑a_i s[n-i].
2. What are the Yule-Walker normal equations?
Set of matrix equations ∑a_i R[|k-i|] = R[k] derived by minimizing mean squared prediction error.
3. Why is speech analyzed in short frames?
Because speech is non-stationary over long durations but quasi-stationary over short 20-30 ms windows.
4. Define Prediction Gain (PG).
Ratio of speech signal variance to prediction error variance: PG = 10 log_10(σ_s^2 / σ_e^2) dB.
5. State the computational complexity of the Levinson-Durbin algorithm.
Solves normal equations recursively in O(p^2) operations compared to O(p^3) for direct matrix inversion.
6. What condition on reflection coefficients (k_i) guarantees filter stability?
The all-pole synthesis filter is stable if and only if |k_i| < 1 for all i = 1 …p.
7. Differentiate short-term and long-term linear prediction.
Short-term LP (p ≈10) models vocal tract formants; long-term LP models pitch periodicity T.
8. What is Moving Average (MA) prediction?
Predicts current sample from past prediction errors rather than past speech samples.
9. State the SQNR formula for an N-bit uniform quantizer.
SQNR ≈6.02 N + 1.76 dB for a full-scale sinusoidal signal.
10. State the two Lloyd-Max optimum quantization conditions.
(1) Decision boundary is midpoint of adjacent levels x_k = (y_k + y_k+1)/2; (2) Level y_k is the centroid of the interval PDF.
11. What is logarithmic companding?
Non-uniform quantization technique passing signal through a logarithmic compressor (μ-law / A-law) before uniform quantization.
12. Differentiate forward (AQF) and backward (AQB) adaptive quantization.
AQF calculates step size from input frame and transmits it; AQB estimates step size from past quantized output.
13. Explain the basic principle of Differential PCM (DPCM).
Quantizes the difference d[n] = s[n] - ŝ[n] between current sample and predicted sample.
14. What is Vector Quantization (VQ)?
Quantization technique mapping a k-dimensional vector of samples to the nearest codevector codeword in a codebook.
15. What is the LBG algorithm?
Iterative codebook design algorithm (Generalized Lloyd) alternating between Voronoi partitioning and centroid updating.
